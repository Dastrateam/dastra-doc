# Handleiding

In deze handleiding verplaatst Dastra u in de rol van een verantwoordelijke die instaat voor de naleving van de Algemene Verordening Gegevensbescherming (AVG) binnen zijn organisatie. Aan de hand van dit scenario leert u stap voor stap de verschillende functies van Dastra gebruiken.

Hebt u onderweg hulp nodig, neem dan contact op met het supportteam:

{% content-ref url="../support/README.md" %}
[Ondersteuning](../support/README.md)
{% endcontent-ref %}

## Fictief gebruiksscenario: het bedrijf SHIPBUILDER

In dit scenario bent u de bedrijfsleider van SHIPBUILDER, een organisatie die boten bouwt. Ze bestaat uit 2 juridische entiteiten en 8 afdelingen:

* HR
* Algemeen secretariaat
* Productie
* Marketing en verkoop
* Beveiliging
* IT
* Juridische zaken
* Inkoop

U besluit uw bedrijf in overeenstemming met de AVG te brengen. Nadat u de [aanpak van de CNIL](https://www.cnil.fr/en/sheet-ndeg0-develop-compliance-gdpr) voor AVG-naleving hebt gelezen, gaat u meteen aan de slag.

Begin met het instellen van uw werkruimte in Dastra:

{% content-ref url="step-1.md" %}
[Stap 1: Instellen](step-1.md)
{% endcontent-ref %}

Stel daarna het register op en breng uw gegevens in kaart:

{% content-ref url="step-2.md" %}
[Stap 2: Breng uw persoonsgegevensverwerkingen in kaart en stel een register op](step-2.md)
{% endcontent-ref %}

Beheer vervolgens uw risico's:

{% content-ref url="step-3.md" %}
[Stap 3: Risico's beheren](step-3.md)
{% endcontent-ref %}

Geef daarna prioriteit aan de te nemen corrigerende acties:

{% content-ref url="step-4.md" %}
[Stap 4: Acties prioriteren](step-4.md)
{% endcontent-ref %}

Implementeer de processen die de AVG vereist:

{% content-ref url="step-5.md" %}
[Stap 5: Interne processen implementeren](step-5.md)
{% endcontent-ref %}

Bundel ten slotte uw nalevingsdocumentatie, met name om een eventuele controle door de toezichthoudende autoriteit (zoals de Franse CNIL) het hoofd te bieden, en geef aanvullende informatie aan de operationele medewerkers:

{% content-ref url="step-6.md" %}
[Stap 6: De naleving documenteren](step-6.md)
{% endcontent-ref %}
