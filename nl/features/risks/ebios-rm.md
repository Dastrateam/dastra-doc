# Vergelijking Dastra / eBios RM

Zoek de overeenkomst tussen de elementen van eBios RM en die van de Dastra-module voor risicobeheer.

| EBios RM                           | Dastra                                                |
| ---------------------------------- | ----------------------------------------------------- |
| Beoogd doel (Objective Aimed, OA)  | Gevreesde gebeurtenis                                 |
| Risicobron (Source of Risk, SR)    | Bedreiging                                            |
| Koppeling OA/SR                    | Risicotype                                            |
| Context                            | Object waarop het risico wordt beoordeeld             |
| Ernst                              | Impact (in de app met het label **Ernst**)            |
| Waarschijnlijkheid                 | Waarschijnlijkheid (zo gelabeld in de app)            |

{% hint style="info" %}
Elementen die ontbreken in deze lijst hebben dezelfde definitie.
{% endhint %}
