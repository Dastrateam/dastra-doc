# Geavanceerde functies voor verzoeken van betrokkenen

Deze geavanceerde functies vullen de behandeling van verzoeken aan: u automatiseert acties, delegeert de behandeling aan de eigenaren van activa, beveiligt de uitwisselingen met aanvragers, past de e-mails aan die u verstuurt en bepaalt hoe lang verzoeken worden bewaard.
