# Grundbegriffe der DSGVO

Um die Logik und die Umsetzung der **Datenschutz-Grundverordnung (DSGVO)** gut zu verstehen, finden Sie hier die grundlegenden Begriffe, die Sie beherrschen sollten.\
Jeder Begriff wird auf den folgenden Seiten ausführlich erläutert.

***

Entdecken Sie die wesentlichen Konzepte, auf denen der gesamte Rahmen der DSGVO basiert:

> Verstehen Sie, was personenbezogene Daten sind, was eine Verarbeitung ist und in welchen Fällen die DSGVO gilt.

### 🗂️ Das Verarbeitungsverzeichnis

> Das Verarbeitungsverzeichnis ist das zentrale Instrument der DSGVO-Compliance.\
> Es erfasst die Verarbeitungen, deren Zwecke, die beteiligten Stakeholder und die zugehörigen Schutzmaßnahmen.

> Auskunft, Berichtigung, Widerspruch, Löschung, Datenübertragbarkeit…\
