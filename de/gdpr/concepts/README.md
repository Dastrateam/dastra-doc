# Grundbegriffe der DSGVO

Um die Logik und die Umsetzung der **Datenschutz-Grundverordnung (DSGVO)** zu verstehen, finden Sie hier die grundlegenden Begriffe, die Sie beherrschen sollten. Jeder von ihnen wird auf den folgenden Seiten ausführlich erläutert.

***

Entdecken Sie die wesentlichen Begriffe, auf denen der gesamte Rahmen der DSGVO beruht:

> Verstehen Sie, was personenbezogene Daten sind, was eine Verarbeitung ist und in welchen Fällen die DSGVO gilt.

## Das Verzeichnis von Verarbeitungstätigkeiten

> Das Verzeichnis ist das zentrale Instrument der DSGVO-Compliance. Es listet alle Verarbeitungstätigkeiten auf, ihre Zwecke, die beteiligten Stakeholder und die zugehörigen Schutzmaßnahmen.

{% content-ref url="ropa.md" %}
[Verarbeitungsverzeichnis](ropa.md)
{% endcontent-ref %}

> Auskunft, Berichtigung, Widerspruch, Löschung, Datenübertragbarkeit usw. Entdecken Sie die Rechte, die Einzelpersonen zustehen, und wie Organisationen sie beachten müssen.

## Ausblick: Konvergenz von DSGVO und KI-Verordnung

Die DSGVO bildet das Fundament der **Daten-Governance**. Die **KI-Verordnung**, seit 2024 in Kraft, ergänzt diesen Rahmen, indem sie **KI-Systeme** nach ihrem Risikoniveau reguliert.
