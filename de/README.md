# Einführung in Dastra

**Dastra** ist eine Plattform für Compliance-Management und die Governance von Daten und KI. Sie ermöglicht Datenschutzbeauftragten, Rechts-, Technik- und Fachteams, alle ihre Pflichten aus DSGVO und KI-Verordnung in einer gemeinsamen, geführten Umgebung zu verwalten.

> Mehr zu unserem Ansatz lesen Sie in unserem [Manifest](https://www.dastra.eu/en/mission).
