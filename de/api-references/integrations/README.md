# Integrationen

Google Drive

### Einführung

Der **Dastra Integrations-Marketplace** umfasst alle Konnektoren, mit denen Sie Ihre Daten synchronisieren und Ihre Prozesse zwischen Dastra und den Anwendungen automatisieren können, die Sie täglich nutzen.\
Diese Integrationen erleichtern die Interoperabilität, reduzieren manuelle Eingriffe und gewährleisten eine bessere Konsistenz zwischen Ihren internen Systemen.

Sie finden mehr als fünfzehn einsatzbereite Konnektoren auf der entsprechenden Seite:\
[https://www.dastra.eu/de/integrations](https://www.dastra.eu/de/integrations)

### Hauptvorteile

* **Abbau von Silos**: Lassen Sie wichtige Daten zwischen Ihren Tools fließen (CRM, Office-Suiten, Verwaltungstools...).
* **Automatisierung von Workflows**: Erstellen Sie ereignisgesteuerte Prozesse (neuer Kontakt, Dokumentenunterzeichnung, eingehende Anfrage...).
* **Schnelle Bereitstellung**: Die Konnektoren sind vorkonfiguriert, um den technischen Integrationsaufwand zu minimieren.
* **Abstimmung von Compliance & Governance**: Die angebotenen Flüsse und Felder folgen der Logik der Dastra-Module.
* **Skalierbarkeit**: Erweitern Sie Ihre Umgebung schrittweise ohne Architektureinschränkungen.

### Allgemeine Funktionsweise

1. **Wählen Sie den Konnektor** im Dastra-Marketplace aus.
2. **Konfigurieren Sie die Zuordnungen** zwischen den Objekten der externen Anwendung und denen von Dastra.
3. **Definieren Sie die Synchronisierungsregeln** (Import, Export oder bidirektional).
4. **Autorisieren Sie den Zugriff** über OAuth oder gesicherte Schlüssel.
5. **Aktivieren und überwachen** Sie die Synchronisierungen über Ihr Integrations-Dashboard.

### Verfügbare Konnektoren (Beispiele)

Hier einige aktuell angebotene Integrationen:

* **DocuSign**: Versand von Dokumenten zur Unterzeichnung und automatischer Abruf in Dastra.
* **Sammel-E-Mail-Adresse**: Automatische Umwandlung von E-Mails in Anfragen oder Aufgaben in Dastra.
* **Zapier**: Erstellung benutzerdefinierter Workflows mit mehr als 3.000 Anwendungen.
* **Salesforce**: Synchronisierung von Konten, Kontakten und relevanten Entitäten mit Dastra.
* **Google Sheets / Microsoft Excel**: Import/Export von Listen und strukturierten Daten.
* **Slack**: Benachrichtigungen und Warnungen direkt in Ihren Kollaborationskanälen.

> Dies ist ein Auszug. Neue Konnektoren werden regelmäßig hinzugefügt.

### Schnellstart

#### 1 — Zugang zum Marketplace

Öffnen Sie in Dastra **Mandanteneinstellungen → Integrationen**, um die Liste der Konnektoren anzuzeigen.

#### 2 — Installieren und konfigurieren

Wählen Sie den gewünschten Konnektor und folgen Sie dem Konfigurationsassistenten: Authentifizierung, Zuordnung, Synchronisierungsregeln.

#### 3 — Synchronisierung testen

Überprüfen Sie die Funktionsweise mit einer Testsynchronisierung vor der Inbetriebnahme.

#### 4 — Inbetriebnahme und Überwachung

Aktivieren Sie die dauerhafte Synchronisierung und prüfen Sie die Protokolle, um Status, Fehler oder verarbeitete Daten zu überprüfen.

#### 5 — Aktualisierung und Erweiterungen

Passen Sie die Zuordnungen im Laufe der Entwicklung Ihrer internen Prozesse an.

### Best Practices

* **Definieren Sie eine klare Feldzuordnung** zwischen Dastra und den externen Systemen.
* **Wählen Sie den geeigneten Synchronisierungsmodus** (stündlich, täglich, ereignisgesteuert).
* **Sichern Sie die Zugangsdaten** und erneuern Sie die Schlüssel regelmäßig.
* **Dokumentieren Sie die Datenflüsse**, um internen Anforderungen und Audits gerecht zu werden.
* **Überprüfen Sie die Protokolle** regelmäßig.

### Typische Anwendungsfälle

* Automatische Erstellung von Betroffenenrechte-Anfragen aus einem CRM oder einer dedizierten E-Mail-Adresse.
* Generierung von Dastra-Aktionen aus einem Projektmanagement-Tool.
* Automatische Erfassung von per E-Mail gemeldeten Vorfällen.

### Weiterführende Informationen

Wenn keine Integration Ihrem Bedarf entspricht:

* Sie können die **Dastra REST-API** verwenden, um eigene Skripte zu entwickeln.
* Sie können das Dastra-Team für einen spezifischen Konnektor kontaktieren.
* Weitere technische Informationen finden Sie auf [https://doc.dastra.eu](https://doc.dastra.eu).
