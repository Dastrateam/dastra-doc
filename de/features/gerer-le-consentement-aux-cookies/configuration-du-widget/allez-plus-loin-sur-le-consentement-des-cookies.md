# Weiterführende Cookie-Einwilligung

Das Cookie-Einwilligungsmodul von DASTRA ermöglicht es Ihnen auch, in der Verwaltung Ihrer Cookies noch weiter zu gehen und dafür zu sorgen, dass die Cookie-Einwilligung wirklich effektiv ist.

Zusätzlich zu den Funktionen für Scan, Klassifizierung, Cookie-Widget und Erfassung von Einwilligungsnachweisen ermöglicht Ihnen DASTRA außerdem:

* Zugriff auf eine konfigurierte API
* Implementierung der vorherigen Einwilligung
* Native Integration einer „Google Tag Manager"-Schicht
* Einfügen benutzerdefinierter HTML- oder JavaScript-Code-Snippets
* Erstellung statistischer Berichte
* Integration der Einwilligung
