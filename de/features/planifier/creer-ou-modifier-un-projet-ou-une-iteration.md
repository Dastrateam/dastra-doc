# Ein Projekt oder eine Iteration erstellen oder bearbeiten

## Einleitung

In Dastra:

* bezieht sich ein Projekt auf eine Liste von Aufgaben, die üblicherweise einem funktionalen Bereich entsprechen.
* bezieht sich eine Iteration auf eine Liste von Aufgaben, die üblicherweise Arbeiten entsprechen, die in einem bestimmten Zeitraum erledigt werden müssen.

## Ein Projekt erstellen oder bearbeiten

Klicken Sie im Modul "Planung" auf den Reiter "Projekte".

![Reiter Projekte](<../../.gitbook/assets/image-225.png>)

Sie gelangen zur Projektoberfläche, wo Sie ein neues Projekt erstellen können, indem Sie auf "Projekt erstellen" klicken, oder ein bestehendes bearbeiten können, indem Sie auf die drei Punkte rechts neben dem Projekt und dann auf "Bearbeiten" klicken.

![Schaltfläche "Projekt erstellen"](<../../.gitbook/assets/image-226.png>)

![Dropdown-Menü eines Projekts](<../../.gitbook/assets/image-227.png>)

## Eine Iteration erstellen oder bearbeiten

Klicken Sie im Modul "Planung" auf den Reiter "Iterationen".

![Reiter "Iterationen"](<../../.gitbook/assets/image-228.png>)

Sie gelangen zur Iterationsoberfläche, wo Sie neue Iterationen erstellen können, indem Sie auf "Iteration erstellen" klicken, oder eine bestehende bearbeiten können, indem Sie auf die drei Punkte rechts neben der Iteration und dann auf "Bearbeiten" klicken.

![Schaltfläche "Iteration erstellen"](<../../.gitbook/assets/image-229.png>)

![Dropdown-Menü einer Iteration](<../../.gitbook/assets/image-230.png>)

Ein zweiter Reiter, "Aktuelle Iterationen", ermöglicht es Ihnen, alle Aufgaben zu sehen, die sich in der laufenden Iteration befinden.

![Der Reiter aktuelle Iteration im Planungsmodul](<../../.gitbook/assets/capture-web-4-5-2022-15256-app-dastra-eu.jpeg>)
