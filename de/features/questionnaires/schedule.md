# Einen Fragebogen planen

## Die Planung einer Kampagne

Sobald die Fragebogenvorlage erstellt und angepasst ist, starten Sie eine Kampagne, indem Sie auf die Schaltfläche "Fragebogen planen" klicken.

Es gibt zwei Möglichkeiten, eine Fragebogenkampagne zu versenden:

1. Per E-Mail: Geben Sie den Kampagnennamen und die Befragten an, laden Sie interne wie externe Befragte ein und warten Sie dann auf die Antworten. Diese erhalten eine E-Mail mit einem Link zu einem Online-Bereich, in dem sie ihre Antworten eingeben können.
2. Über einen Freigabelink: Jede Person mit dem Freigabelink kann darauf zugreifen und Befragter des Fragebogens werden; bei jedem Zugriff wird ein Fragebogen erstellt. Der Freigabelink bleibt bis zu seiner Deaktivierung verfügbar.

Es ist möglich, Personen, die den Fragebogen noch nicht beantwortet haben, erneut zu erinnern.

## Den Fragebogen mit anderen Objekten in Dastra verknüpfen

Es ist möglich, den Fragebogen mit einem anderen spezifischen Modul zu verknüpfen. Weisen Sie dazu bei der Konfiguration Ihrer Fragebogenvorlage, nachdem Sie ihr einen Namen und eine Beschreibung gegeben haben, ein Element zu, das Gegenstand des Fragebogens sein wird.

![Auswahl des bewerteten Elements in der Konfiguration](<../../.gitbook/assets/fragebögen konfig.png>)

Wenn Ihr Fragebogen bereits erstellt wurde, ist es dennoch möglich, nachträglich ein Element zuzuweisen. Gehen Sie in den Fragebogen, klicken Sie auf die Schaltfläche "Vorlage bearbeiten" und dann auf die Schaltfläche "Konfigurieren" unterhalb der Schaltfläche "Speichern". Sie gelangen dann zurück zur ursprünglichen Konfigurationsregisterkarte der Vorlage.

Diese Objekte können Akteure, Assets, Anwendungen, Datenverarbeitungen, Datenschutzvorfälle, Betroffenenanfragen, Datensätze, Sicherheitsmaßnahmen, Risikobewertungen sein.

Wenn Sie dann Ihren Fragebogen planen, erscheint ein neues Feld "Mit dem Fragebogen verknüpftes Objekt". Der Selektor ermöglicht es Ihnen, genauer auszuwählen, mit welchem Objekt Sie den Fragebogen verknüpfen möchten.

![Ein Beispiel für ein zugewiesenes Element: eine Datenverarbeitung](<../../.gitbook/assets/fragebögen konfig2.png>)

{% hint style="info" %}
Sie können einen Fragebogen nur mit einem einzigen Objekt in Dastra verknüpfen.
{% endhint %}
