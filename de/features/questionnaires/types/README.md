# Fragebogentypen

Dastra bietet eine Bibliothek automatisierter Fragebogenvorlagen, die auf bestimmte Compliance-Anforderungen zugeschnitten sind. Über generische Fragebögen hinaus sind mehrere Typen so konzipiert, dass sie sich direkt in Ihre Verarbeitungstätigkeiten einfügen und strukturierte Bewertungen erzeugen.
