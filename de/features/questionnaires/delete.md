# Einen Fragebogen oder eine Vorlage löschen

## Ein Audit löschen

Bevor ein Audit gelöscht wird, haben wir eine Sicherheitsmaßnahme eingerichtet: eine Archivierungsphase. Diese Phase ermöglicht es, das Dokument vor der endgültigen Löschung aufzubewahren. Dies funktioniert wie ein Papierkorb.

### Archivierung

Zunächst müssen Sie das Audit über die Schaltfläche "**In den Papierkorb verschieben**" im Menü des Audits archivieren. Um das Menü anzuzeigen, gehen Sie auf die drei kleinen Punkte in der Audit-Liste.

<figure><img src="../../.gitbook/assets/frageogen löschen.png" alt=""><figcaption><p>Die Schaltfläche befindet sich unten in der Liste</p></figcaption></figure>

Klicken Sie auf **In den Papierkorb verschieben** und Ihr Audit wird archiviert.

### Endgültige Löschung eines Audits

Um ein Audit **endgültig zu löschen**, müssen Sie die Archive anzeigen und die Löschung durchführen.

<figure><img src="../../.gitbook/assets/frageogen löschen2.png" alt=""><figcaption><p>Kontrollkästchen zum Anzeigen der Archive</p></figcaption></figure>

Anschließend müssen Sie das Audit einfach über das Audit-Menü löschen

<figure><img src="../../.gitbook/assets/frageogen löschen3.png" alt=""><figcaption><p>Sie können Ihr Audit bei Bedarf auch wiederherstellen</p></figcaption></figure>

## Eine Audit-Vorlage löschen

Um eine Audit-Vorlage zu löschen, gehen Sie zur Vorlagenliste und wählen Sie im Vorlagenmenü die Schaltfläche **Löschen**.

<figure><img src="../../.gitbook/assets/frageogen löschen4.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Achtung, es gibt keine Archivierung für Audit-Vorlagen. Denken Sie daran, die Vorlage im JSON-Format herunterzuladen, wenn Sie eine Kopie zum erneuten Import aufbewahren möchten.
{% endhint %}
