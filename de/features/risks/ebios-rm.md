# Vergleich Dastra / eBios RM

Hier finden Sie die Entsprechungen zwischen den Elementen von eBios RM und denen des Risikomanagement-Moduls von Dastra.

| EBios RM | Dastra |
| --- | --- |
| Angestrebtes Ziel (Objective Aimed, OA) | Befürchtetes Ereignis |
| Risikoquellen (Sources of Risk, SR) | Bedrohung |
| Paar OA/SR | Risikotyp |
| Kontext | Objekt, auf dem das Risiko bewertet wird |
| Schwere | Auswirkung (in der App als **Schweregrad** bezeichnet) |
| Wahrscheinlichkeit | Wahrscheinlichkeit (in der App als **Wahrscheinlichkeit** bezeichnet) |

{% hint style="info" %}
Elemente, die in dieser Liste fehlen, haben dieselbe Definition.
{% endhint %}
