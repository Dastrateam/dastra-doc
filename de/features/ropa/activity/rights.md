# Betroffenenrechte

Jede betroffene Person hat Rechte an den Daten, die sie betreffen. Diese Rechte, geregelt in den [**Artikeln 15 ff. der DSGVO**](https://dsgvo-gesetz.de/art-15-dsgvo/), gelten je nach der für die Verarbeitung gewählten Rechtsgrundlage oder dem anwendbaren Rechtsrahmen. So gilt das Recht auf Datenübertragbarkeit zum Beispiel nur für Verarbeitungen, die auf einer Einwilligung beruhen oder zur Erfüllung eines Vertrags erforderlich sind.

Für jedes Recht geben Sie an, wie es ausgeübt wird. Die Ausübung kann automatisiert sein, zum Beispiel wenn Personen ihr Recht direkt in einer Online-Umgebung ausüben. Andernfalls erfolgt sie manuell oder auf Anfrage.

Im Abschnitt **Rechte von Personen** legen Sie fest, wie betroffene Personen ihre Rechte für diese Verarbeitungstätigkeit ausüben können. Im Rahmen der Rechenschaftspflicht müssen Sie das Verfahren festlegen, das sicherstellt, dass betroffene Personen ihre Rechte tatsächlich ausüben können. Als bewährte Praxis können Sie ein eigenes Verfahren verfassen: Verweisen Sie in diesem Fall in diesem Abschnitt darauf.

## Die Ausübung der Rechte beschreiben

1. Beschreiben Sie unter **Allgemeine Informationen zu Ihren Rechten** das allgemeine Verfahren zur Ausübung der Rechte, zum Beispiel indem Sie angeben, ob eine allgemeine Richtlinie zu Rechten vorhanden ist.
2. Wählen Sie für jedes Recht aus, wie es ausgeübt wird: **Keine**, **Manuell oder auf Anfrage**, **Automatisch** oder **Nicht zutreffend**.
3. Ergänzen Sie nach der Auswahl bei Bedarf Einzelheiten im Feld **Anmerkungen**.

Folgende Rechte werden aufgelistet:

* **Recht auf Information**
* **Recht auf Auskunft**
* **Recht auf Löschung (Recht auf Vergessenwerden)**
* **Recht auf Berichtigung**
* **Recht auf Einschränkung**
* **Recht auf Datenübertragbarkeit**
* **Widerspruchsrecht**
* **Das Recht, über den Verbleib der Daten nach dem Tod zu entscheiden**: Dieses Recht, das Artikel 85 des französischen Datenschutzgesetzes vorsieht, erlaubt es Personen, dem Verantwortlichen besondere Anweisungen zur Speicherung, Löschung und Weitergabe ihrer personenbezogenen Daten nach ihrem Tod zu erteilen.

Fahren Sie mit der Maus über das Informationssymbol neben einem Recht, um eine Erinnerung daran anzuzeigen, was es umfasst.

## Nach Rechtsgrundlagen gefilterte Rechte

Dastra blendet die Rechte aus, die nach den Rechtsgrundlagen der im Abschnitt **Zweck** erfassten Zwecke nicht gelten. Ein Recht wird nur ausgeblendet, wenn es für keinen der Zwecke der Verarbeitungstätigkeit gilt:

| Rechtsgrundlage | Ausgeblendete Rechte |
| --- | --- |
| Vertrag oder vorvertragliche Maßnahmen | Widerspruchsrecht |
| Berechtigte Interessen des Verantwortlichen oder eines Dritten | Recht auf Datenübertragbarkeit |
| Gesetzliche Verpflichtung | Recht auf Datenübertragbarkeit, Widerspruchsrecht, Recht auf Löschung |
| Ausführung einer Aufgabe von öffentlichem Interesse oder im Rahmen der Ausübung öffentlicher Gewalt | Recht auf Datenübertragbarkeit, Recht auf Löschung |
| Schutz lebenswichtiger Interessen | Recht auf Datenübertragbarkeit, Widerspruchsrecht |
| Einwilligung, Sonstiges | Keine |

Sind Rechte ausgeblendet, erklärt eine Meldung den Grund. Aktivieren Sie **Ausgeblendete Rechte anzeigen**, um sie trotzdem anzuzeigen und auszufüllen.
