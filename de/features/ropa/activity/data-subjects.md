# Betroffene Personen

[**Artikel 30 der DSGVO**](https://dsgvo-gesetz.de/art-30-dsgvo/) verlangt, dass das Verzeichnis eine Beschreibung der Kategorien der von der Verarbeitung betroffenen Personen enthält. Wenn Sie die betroffenen Personen identifizieren, können Sie die Sensibilität der Verarbeitungstätigkeit analysieren und das Risiko für diese Personen besser bewerten. Eine Verarbeitungstätigkeit hat zum Beispiel nicht dieselbe Sensibilität, wenn sie Minderjährige in einem Krankenhaus betrifft, wie wenn sie eine Kundendatei in einem Geschäft betrifft.

Eine betroffene Person ist jede natürliche Person, deren Daten im Rahmen der Verarbeitungstätigkeit erhoben, gespeichert oder verarbeitet werden. In einem Bewerbungsverfahren ist zum Beispiel jeder Bewerber, der sich auf eine Stelle bewirbt, eine betroffene Person.

## Eine Kategorie betroffener Personen hinzufügen

1. Klicken Sie im Abschnitt **Betroffene Person** auf **Eine Kategorie betroffener Personen hinzufügen**.
2. Wählen Sie die Kategorie betroffener Personen aus Ihrem Verzeichnis aus oder legen Sie in der Liste eine neue an.
3. Füllen Sie optional das Feld **Zusätzlicher Kommentar** aus.
4. Geben Sie optional die **Anzahl der betroffenen Personen** an, also die ungefähre Höchstzahl der betroffenen Personen. Wählen Sie **Auswahl**, um eine Größenordnung zu wählen (von 1 Person bis weniger als 100.000.000 Personen), oder **Bitte einen Wert eingeben**, um eine Zahl einzutragen. Für Beschäftigte geben Sie zum Beispiel die ungefähre Zahl der Beschäftigten der Organisation an.
5. Klicken Sie auf **Hinzufügen**.

Die Kategorien werden mit ihrem Höchstvolumen (**Anzahl**) aufgelistet. Klicken Sie auf eine Kategorie, um sie zu bearbeiten, oder nutzen Sie das Menü **...**, um sie zu bearbeiten oder zu löschen.

## Schutzbedürftige Personen

Die Option **Betroffene schutzbedürftige Personen** wird in Ihrem Verzeichnis an der Kategorie betroffener Personen selbst festgelegt. Aktivieren Sie sie, wenn die Kategorie schutzbedürftige Personen umfasst, also Personen in einer Situation der Unterlegenheit, zum Beispiel Minderjährige, Beschäftigte oder ältere Menschen. Der Abschnitt **Betroffene Person** zeigt dann für diese Kategorie **Betroffene schutzbedürftige Personen**.

{% hint style="info" %}
Die Anwesenheit von Minderjährigen oder schutzbedürftigen Personen und eine große Zahl betroffener Personen erhöhen den Indikator **Sensibilität** der Verarbeitungstätigkeit.
{% endhint %}
