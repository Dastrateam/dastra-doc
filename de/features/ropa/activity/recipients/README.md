# Empfänger

[**Artikel 30 Abs. 1 Buchst. d der DSGVO**](https://dsgvo-gesetz.de/art-30-dsgvo/) verlangt, dass das Verzeichnis „_die Kategorien von Empfängern, gegenüber denen die personenbezogenen Daten offengelegt worden sind oder noch offengelegt werden, einschließlich Empfänger in Drittländern oder internationalen Organisationen_“ enthält.

[**Artikel 4 der DSGVO**](https://dsgvo-gesetz.de/art-4-dsgvo/) definiert den Empfänger als „_eine natürliche oder juristische Person, Behörde, Einrichtung oder andere Stelle, der personenbezogene Daten offengelegt werden, unabhängig davon, ob es sich bei ihr um einen Dritten handelt oder nicht. Behörden, die im Rahmen eines bestimmten Untersuchungsauftrags nach dem Unionsrecht oder dem Recht der Mitgliedstaaten möglicherweise personenbezogene Daten erhalten, gelten jedoch nicht als Empfänger; die Verarbeitung dieser Daten durch die genannten Behörden erfolgt im Einklang mit den geltenden Datenschutzvorschriften gemäß den Zwecken der Verarbeitung_“.

Mit anderen Worten umfasst der Begriff Empfänger alle Stellen, die auf die Daten zugreifen, mit Ausnahme der Behörden (berechtigte Dritte wie eine Aufsichtsbehörde, die Kriminalpolizei im Rahmen einer strafrechtlichen Untersuchung oder die Finanzverwaltung). Dazu gehören die internen Abteilungen des Verantwortlichen (zum Beispiel die Personalabteilung), Auftragsverarbeiter, gemeinsam Verantwortliche und andere Verantwortliche (zum Beispiel Geschäftspartner).

## Einen Empfänger hinzufügen

1. Klicken Sie im Abschnitt **Empfänger** auf **Empfänger erstellen**.
2. Wählen Sie unter **Kategorie** die Art des Empfängers: **Interne Empfänger**, **Auftragsverarbeiter**, **Dritte: Externe Organisation**, **Autorisierte Dritte**, **Gemeinsam verantwortlich** oder **Betroffene Person**.
3. Identifizieren Sie den Empfänger:
   * **Verzeichnis der Stakeholder (empfohlen)**: Wählen Sie einen Stakeholder aus Ihrem Stakeholder-Verzeichnis aus oder legen Sie einen neuen an. Ist der Empfänger im Verzeichnis erfasst, können Sie die Verarbeitungstätigkeiten kartieren, die mit diesem Stakeholder zusammenhängen.
   * **Bitte wählen Sie eine Organisationseinheit aus**: Wählen Sie eine Ihrer Organisationseinheiten aus, zum Beispiel eine interne Abteilung.
   * **Freie Eingabe**: Geben Sie eine frei gewählte Bezeichnung ein. Diese Option ist für Auftragsverarbeiter nicht verfügbar. Für die Kategorie **Betroffene Person** ist sie die einzige Option.
4. Beschreiben Sie optional unter **Beschreibung der mit den Daten durchgeführten Vorgänge**, was der Empfänger mit den Daten tut.
5. Hat der Empfänger Zugriff auf die Daten, aktivieren Sie **Hat der Empfänger Zugriff auf die Daten?** und geben Sie an, ob er **Zugriff auf alle Daten (Standard)** oder **Zugriff auf bestimmte Datensätze** hat. Wählen Sie im zweiten Fall die betreffenden Datensätze aus.
6. Werden die Daten außerhalb der EU übermittelt, erfassen Sie die Übermittlung im selben Fenster (siehe [Datenübermittlung außerhalb der EU](transfers.md)).
7. Klicken Sie auf **Hinzufügen**.

{% hint style="info" %}
Dastra hilft Ihnen, die Liste zu vervollständigen:

* Die im Abschnitt **Interessengruppen** erfassten gemeinsam Verantwortlichen erscheinen als **Empfohlene Empfänger**: Klicken Sie auf **Hinzufügen**, um sie zu übernehmen.
* Wählen Sie einen Auftragsverarbeiter, dessen weitere Auftragsverarbeiter im Stakeholder-Verzeichnis dokumentiert sind, können Sie diese gleichzeitig hinzufügen: **Fügen Sie die mit dem Stakeholder verbundenen Unterauftragnehmer hinzu**.
* Befindet sich der gewählte Stakeholder oder die gewählte Organisationseinheit in einem anderen Land, schlägt Dastra vor, eine Übermittlung hinzuzufügen.
{% endhint %}

Die Empfänger werden mit ihrer **Kategorie** und ihren **Übertragungen** aufgelistet. Mit **Neu organisieren nach** sortieren Sie sie nach Name oder Kategorie. Im Menü **...** eines Empfängers können Sie ihn je nach Kategorie **Bearbeiten**, seinen Stakeholder mit **Den verbundenen Stakeholder bearbeiten** öffnen, **Einen weiteren Subunternehmer hinzufügen**, **Versenden Sie einen Fragebogen an Ihren Auftragsverarbeiter** oder ihn **Löschen**.

## Einen weiteren Auftragsverarbeiter hinzufügen

Ein Auftragsverarbeiter kann selbst weitere Auftragsverarbeiter für die Verarbeitung der Daten einsetzen. Um sie zu erfassen, öffnen Sie das Menü **...** eines Empfängers der Kategorie **Auftragsverarbeiter** und klicken Sie auf **Einen weiteren Subunternehmer hinzufügen**. Der weitere Auftragsverarbeiter wird unter seinem Auftragsverarbeiter angezeigt.

## Einen Dienstleister bewerten

Klicken Sie im Menü **...** eines im Verzeichnis erfassten Empfängers auf **Versenden Sie einen Fragebogen an Ihren Auftragsverarbeiter**, um diesen Stakeholder mit einem Fragebogen zu bewerten.

## Einen DPA erstellen

Wenn Sie das Modul Verträge nutzen, können Sie direkt aus der Verarbeitungstätigkeit einen Auftragsverarbeitungsvertrag (Data Processing Agreement, DPA) erstellen. In der Liste der Empfänger erscheint bei den Auftragsverarbeitern einer Tätigkeit als Verantwortlicher, die im Verzeichnis erfasst sind, die Schaltfläche **DPA**. Sie öffnet die Vertragserstellung mit der DPA-Vorlage, die bereits mit der Verarbeitungstätigkeit und dem Auftragsverarbeiter ausgefüllt ist. Dieselbe Aktion steht im Menü **...** zur Verfügung (**DPA generieren**).

Ebenso erstellt die Schaltfläche **CCT-Übertragung** die entsprechenden Standardvertragsklauseln, wenn für einen Auftragsverarbeiter oder für einen Dritten einer Tätigkeit als Verantwortlicher eine Übermittlung erfasst ist.
