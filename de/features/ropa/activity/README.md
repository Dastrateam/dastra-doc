# Eine Verarbeitung ausfüllen

## Ein Erstellungsprozess, der Sie Schritt für Schritt führt

Die Dastra-Anwendung begleitet Sie bei jedem Schritt der Erstellung einer Verarbeitungstätigkeit und lässt Ihnen dabei die Freiheit, in Ihrem eigenen Tempo zu arbeiten. Profitieren Sie bei jedem Schritt von Hinweisen und erfüllen Sie die Anforderungen der DSGVO.

## Der Dastra-Fragebogen zur Verarbeitung

Der Fragebogen zur Verarbeitung erfasst die für eine Verarbeitungstätigkeit erforderlichen Informationen. Er ist in Abschnitte gegliedert, die in der Navigation links neben der Verarbeitungstätigkeit aufgeführt sind. Neben den meisten Abschnitten zeigt die Navigation an, wie viele Einträge Sie bereits erfasst haben (Zwecke, Daten, Empfänger usw.). Mit **Weiter** und **Zurück** am Seitenende wechseln Sie von einem Abschnitt zum anderen.

Eine Verarbeitungstätigkeit als **Verantwortlicher** hat 12 Abschnitte:

* **Allgemeines**: Erfassen Sie allgemeine Informationen zur Verarbeitung, etwa Name, Organisationseinheit und Beschreibung.

{% content-ref url="general.md" %}
[Allgemein](general.md)
{% endcontent-ref %}

* **Interessengruppen**: Listen Sie die Nutzer auf, die für die Verarbeitungstätigkeit zuständig sind, und die beteiligten Stakeholder, zum Beispiel gemeinsam Verantwortliche oder den für die Umsetzung der Verarbeitung Zuständigen.

{% content-ref url="stakeholders.md" %}
[Stakeholder](stakeholders.md)
{% endcontent-ref %}

* **Zweck**: Beschreiben Sie die Zwecke der Verarbeitung und die Rechtsgrundlage jedes Zwecks.

{% content-ref url="purposes.md" %}
[Zwecke](purposes.md)
{% endcontent-ref %}

* **Assets**: Listen Sie die internen oder externen Assets der Organisation auf (Anwendungen, Software, Server usw.), die die Verarbeitungstätigkeit unterstützen.

{% content-ref url="assets.md" %}
[Assets](assets.md)
{% endcontent-ref %}

* **Daten**: Listen Sie die Kategorien der verarbeiteten Daten und ihre Regeln zur Speicherdauer auf.

{% content-ref url="datasets.md" %}
[Daten und Speicherdauer](datasets.md)
{% endcontent-ref %}

* **Betroffene Person**: Listen Sie die Kategorien betroffener Personen auf, die von der Verarbeitung betroffen sind.

{% content-ref url="data-subjects.md" %}
[Betroffene Personen](data-subjects.md)
{% endcontent-ref %}

* **Rechte von Personen**: Beschreiben Sie, wie betroffene Personen jedes ihrer Rechte ausüben können.

{% content-ref url="rights.md" %}
[Betroffenenrechte](rights.md)
{% endcontent-ref %}

* **Empfänger**: Listen Sie die Empfänger der Daten auf. Hier melden Sie auch Datenübermittlungen außerhalb der EU.

{% content-ref url="recipients/README.md" %}
[Empfänger](recipients/README.md)
{% endcontent-ref %}

{% content-ref url="recipients/transfers.md" %}
[Datenübermittlung außerhalb der EU](recipients/transfers.md)
{% endcontent-ref %}

* **Maßnahmen**: Beschreiben Sie die technischen und organisatorischen Sicherheitsmaßnahmen, die die Daten schützen.

{% content-ref url="security.md" %}
[Sicherheitsmaßnahmen](security.md)
{% endcontent-ref %}

* **Folgenabschätzung**: Beurteilen Sie, ob die Verarbeitung eine Datenschutz-Folgenabschätzung (DSFA) erfordert.

{% content-ref url="impact-analysis.md" %}
[Datenschutz-Folgenabschätzung](impact-analysis.md)
{% endcontent-ref %}

* **Dokumentation**: Dokumentieren Sie die Verarbeitungstätigkeit und laden Sie weitere Dokumente hoch (zum Beispiel Verhaltenskodex, Datenschutzrichtlinie usw.).

{% content-ref url="documents.md" %}
[Dokumente](documents.md)
{% endcontent-ref %}

* **Zusammenfassung**: Prüfen Sie alles, was Sie in den vorherigen Abschnitten erfasst haben, auf einer einzigen Seite.

{% content-ref url="summary.md" %}
[Zusammenfassung](summary.md)
{% endcontent-ref %}

{% hint style="info" %}
Eine Verarbeitungstätigkeit als **Auftragsverarbeiter** folgt demselben Ablauf, mit zwei Unterschieden: Ein Abschnitt **Kunden**, der nach **Daten** steht, listet die Kunden auf, in deren Auftrag Sie die Daten verarbeiten, und es gibt keinen Abschnitt **Folgenabschätzung**. Siehe [Verzeichnis „Auftragsverarbeiter“](../processor.md).
{% endhint %}

Auch benutzerdefinierte Felder Ihrer Organisation können in jedem dieser Abschnitte erscheinen.

Sobald Sie die Informationen eingegeben haben, die Ihnen vorliegen, können Sie damit beginnen, zu ermitteln, was noch zu tun ist.

## Indikatoren zu Verarbeitungstätigkeiten

Der Fragebogen ist nicht die einzige Orientierungshilfe beim Ausfüllen einer Verarbeitungstätigkeit. Drei Indikatoren helfen Ihnen einzuschätzen, wie vollständig, wie gut dokumentiert und wie sensibel die Tätigkeit ist. Sie werden im Bereich rechts neben der Verarbeitungstätigkeit und in ihrem Abschnitt **Zusammenfassung** angezeigt:

* **Fortschritt** (Gesamtfortschritt)
* **Qualität**
* **Sensibilität**

### Gesamtfortschritt

Dieser Prozentsatz wird aus einer Reihe von Prüfungen berechnet, die kontrollieren, ob die Verarbeitungstätigkeit alle verpflichtenden Elemente enthält: Zwecke, Daten mit ihren Datenfeldern und Regeln zur Speicherdauer, Kategorien betroffener Personen, Empfänger, Sicherheitsmaßnahmen und, bei einer Tätigkeit als Auftragsverarbeiter, die Verantwortlichen.

Diese Elemente entsprechen den Informationen, die Artikel 30 der DSGVO für das Verzeichnis von Verarbeitungstätigkeiten verlangt.

### Qualität

Dieser Prozentsatz wird aus einer Reihe von Prüfungen zur Qualität der Elemente berechnet, die Sie im Formular erfasst haben. Diese Prüfungen kontrollieren zum Beispiel, dass:

* jeder Zweck eine Rechtsgrundlage hat,
* mindestens ein Asset mit der Verarbeitungstätigkeit verknüpft ist,
* die Ausübung der Betroffenenrechte beschrieben ist,
* der Abschnitt **Folgenabschätzung** ausgefüllt ist und, wenn eine DSFA erforderlich ist, diese durchgeführt wurde,
* der Verarbeitungstätigkeit ein Nutzer als **Genehmiger** zugewiesen ist,
* für jeden Empfänger außerhalb der EU eine Übermittlung gemeldet ist.

Diese Kriterien gehen über Artikel 30 der DSGVO hinaus und helfen Ihnen, weitere Pflichten vorauszuplanen. Zum Beispiel:

* eine DSFA für eine Verarbeitungstätigkeit durchführen, die eine solche erfordert,
* die Software ermitteln, die die Verarbeitungstätigkeit unterstützt, denn sie verrät Ihnen deren Hersteller: So erkennen Sie den Auftragsverarbeiter und mögliche Datenübermittlungen.

### Sensibilität

Dieser Indikator zeigt das **Sensibilitätsniveau der Verarbeitungstätigkeit** an.

Er wird automatisch anhand der folgenden **Kriterien** berechnet:

* Vorhandensein sensibler Daten,
* Vorhandensein von Minderjährigen und/oder schutzbedürftigen Personen unter den betroffenen Personen,
* große Anzahl betroffener Personen,
* Vorhandensein eines Auftragsverarbeiters,
* Vorhandensein einer Übermittlung in ein Land ohne angemessenes Schutzniveau,
* Notwendigkeit, eine DSFA durchzuführen.
