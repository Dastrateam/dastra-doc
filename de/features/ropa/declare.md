# Eine Verarbeitung anlegen

## Definition der Datenverarbeitung

Eine Verarbeitungstätigkeit ist ein Vorgang oder eine Reihe von Vorgängen mit personenbezogenen Daten, zum Beispiel die Gehaltsabrechnung. Alle Verarbeitungstätigkeiten zusammen bilden das Verarbeitungsverzeichnis.

## Eine Verarbeitungstätigkeit anlegen

Um eine Verarbeitungstätigkeit anzulegen, öffnen Sie das Verarbeitungsverzeichnis und klicken Sie auf **Erstellen Sie eine Datenverarbeitung**. Das Fenster **Erstellung einer Datenverarbeitung** bietet vier Optionen:

* **Erstellen mit KI-Assistent**: Beschreiben Sie Ihre Verarbeitungstätigkeit in wenigen Worten, und unser KI-Assistent (Beta) erzeugt sie für Sie, sofern diese Funktion in Ihrem Mandanten aktiviert ist. Die KI-Schaltfläche neben **Erstellen Sie eine Datenverarbeitung** öffnet diese Option direkt.
* **Basierend auf einer Vorlage**: Beginnen Sie mit einer unserer vordefinierten Vorlagen (siehe [Eine Verarbeitungsvorlage verwenden](templates.md)).
* **Ausgehend von einem Asset**: Legen Sie eine Verarbeitungstätigkeit aus einem Asset und den zugehörigen Daten an.
* **Von Grund auf neu**: Legen Sie eine neue Verarbeitungstätigkeit von Grund auf an.

<figure><img src="../../.gitbook/assets/ropa-declare-1.png" alt="Fenster zum Anlegen einer Verarbeitungstätigkeit mit den vier Optionen"><figcaption><p>Wählen, wie die neue Verarbeitungstätigkeit angelegt wird</p></figcaption></figure>

Geben Sie bei **Von Grund auf neu** den **Name der Datenverarbeitung** ein, wählen Sie die **Organisationseinheit** und klicken Sie auf **Erstellen Sie eine Datenverarbeitung**. Sie gelangen dann zum Fragebogen, in dem Sie alle erforderlichen Informationen ergänzen können.

## Eine Verarbeitungstätigkeit als Auftragsverarbeiter anlegen

Eine Verarbeitungstätigkeit als Auftragsverarbeiter anzulegen geht so: Aktivieren Sie beim Anlegen mit **Von Grund auf neu** (oder **Erstellen mit KI-Assistent**) den Schalter **Verarbeitungstätigkeit als Auftragsverarbeiter**.

<figure><img src="../../.gitbook/assets/ropa-declare-2.png" alt="Schalter Verarbeitungstätigkeit als Auftragsverarbeiter im Fenster zum Anlegen"><figcaption><p>Eine Verarbeitungstätigkeit als Auftragsverarbeiter anlegen</p></figcaption></figure>

Sie gelangen dann direkt zur Dokumentation einer Verarbeitungstätigkeit als Auftragsverarbeiter, in der Sie im Abschnitt **Kunden** Ihre Verantwortlichen (in der Regel Ihre Kunden) angeben können.

## Eine Verarbeitungstätigkeit ändern

Um eine bestehende Verarbeitungstätigkeit zu ändern, klicken Sie im Verzeichnis auf ihre Zeile oder öffnen Sie das Menü am Ende der Zeile und wählen Sie **Bearbeiten**:

<figure><img src="../../.gitbook/assets/ropa-declare-3.png" alt="Aktionsmenü einer Zeile einer Verarbeitungstätigkeit mit dem Eintrag Bearbeiten"><figcaption><p>Eine Verarbeitungstätigkeit zum Bearbeiten öffnen</p></figcaption></figure>

Die Abschnitte des Fragebogens stehen links auf dem Bildschirm: Klicken Sie auf einen Abschnitt, um direkt dorthin zu springen, oder nutzen Sie unten auf der Seite die Schaltflächen **Zurück**, **Weiter zum Abschnitt** und **Weiter**. Klicken Sie auf **Speichern**, um Ihre Arbeit zu sichern.
