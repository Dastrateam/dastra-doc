# Den Aufgaben-Workflow anpassen

Jede Aufgabe durchläuft einen Workflow: Sie wandert von einem Schritt zum nächsten, bis sie geschlossen ist. Die Schritte sind die Spalten der Ansicht **Spalten**. Sie können sie an die Verfolgungsregeln Ihrer Organisation anpassen.

## Die Standardschritte

Ein neuer Mandant wird mit vier Schritten geliefert. Jeder ist mit einem internen Status verknüpft, **Neu**, **Aktiv** oder **Geschlossen**, der nicht vom Namen des Schritts abhängt:

| Schritt | Interner Status |
| --- | --- |
| **Neu** | **Neu** |
| **Informationen anfordern** | **Aktiv** |
| **In Bearbeitung** | **Aktiv** |
| **Fait** | **Geschlossen** |

Der letzte Schritt, **Fait**, ist der Endschritt: Eine Aufgabe, die ihn erreicht, gilt als erledigt.

## Die Schritte bearbeiten

1. Klicken Sie im Seitenmenü auf **Mandanteneinstellungen** und dann im Bereich **Prozess** auf **Prozessschritte**. Sie können auch auf der Seite **Kanban-Board** auf den Pfeil der Schaltfläche **Aufgabe erstellen** und dann auf **Spalten konfigurieren** klicken.
2. Wählen Sie in der Liste oben auf der Seite **Prozessmanagement** den Objekttyp **Aufgaben**.
3. Fügen Sie Schritte hinzu, benennen Sie sie um oder ordnen Sie sie neu an, wählen Sie ihren internen Status und klicken Sie dann auf **Speichern**.

<figure><img src="../../.gitbook/assets/tasks-workflow-1.png" alt="Die Seite Prozessmanagement mit den vier Schritten des Aufgaben-Workflows und ihrem internen Status"><figcaption><p>Die Schritte des Aufgaben-Workflows</p></figcaption></figure>

Diese Seite ist Nutzern vorbehalten, die die erweiterten Einstellungen verwalten dürfen. Das genaue Vorgehen (einen Schritt hinzufügen, anordnen und löschen) ist unter [Prozessschritte](../settings/workflow-stages.md) beschrieben. Sie können einen Schritt auch direkt in der Kopfzeile seiner Spalte in der Ansicht **Spalten** umbenennen.

## Aufgaben mit Tags einordnen

Mit dem Feld **Tags** im Aufgabenfenster ordnen Sie Aufgaben ein, um sie schneller zu finden: Der Filter **Nach Tags filtern** nutzt sie in jeder Ansicht. Tags werden unter **Mandanteneinstellungen**, Bereich **Prozess**, Eintrag **Tags** verwaltet.
