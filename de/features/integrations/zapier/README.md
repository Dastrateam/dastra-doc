## Über Zapier

Zapier ist ein Online-Automatisierungstool, das Ihre Anwendungen und Dienste miteinander verbindet. Sie können zwei oder mehr Anwendungen verbinden, um wiederkehrende Aufgaben zu automatisieren, ohne zu programmieren und ohne auf Entwickler angewiesen zu sein.

Mit Zapier richten Sie Zaps (oder Integrationen) ein.

Ein Zap ist ein automatisierter Workflow, der Ihre Anwendungen und Dienste miteinander verbindet. Jeder Zap besteht aus einem Trigger und einer oder mehreren Aktionen. Wenn Sie Ihren Zap aktivieren, führt er die Aktionen jedes Mal aus, wenn das Trigger-Ereignis eintritt.

## Die drei wichtigsten Konzepte <a href="#chapter-1" id="chapter-1"></a>

* **Trigger:**\
  Ein Ereignis, das einen Zap startet. Wenn Sie beispielsweise jedes Mal eine SMS senden möchten, wenn Sie eine E-Mail erhalten, ist der Trigger „neue E-Mail im Posteingang“.
* **Aktion:**\
  Ein Ereignis, das ein Zap nach dem Auslösen ausführt. Im selben Beispiel ist die Aktion „Textnachricht senden“.
* **Zap:**\
  Ein Trigger und eine Reihe von Aktionen, die zusammen einen automatisierten Workflow bilden. Zum Beispiel: jedes Mal eine SMS senden, wenn Sie eine E-Mail erhalten.

## Vorlagen für eine schnelle Einrichtung

Wir haben automatisierte Workflow-Vorlagen vorkonfiguriert, die Sie sofort einrichten können. Etwa zehn Vorlagen sind bereits verfügbar, auf unserer [Integrationsseite](https://www.dastra.eu/en/integrations) oder direkt im [Bereich Integrationen](https://app.dastra.eu/workspace/0/settings/integrations) der Dastra-Webanwendung.

Wir veröffentlichen regelmäßig neue Vorlagen, um Ihren Automatisierungsbedarf zu decken. Sie können uns auch Ihre Ideen für automatisierte Workflows senden, damit wir sie als Vorlagen anbieten.

## Ein anpassbarer Integrationseditor <a href="#chapter-3" id="chapter-3"></a>

Um einen Workflow zu automatisieren, für den es noch keine Vorlage gibt, oder um eine bestehende Vorlage leicht anzupassen, verwenden Sie [den Zap-Editor von Zapier](https://zapier.com/apps/dastra/integrations).

Mit dem Zap-Editor erstellen Sie einen Zap von Grund auf, ohne eine einzige Zeile Code zu schreiben.

Wählen Sie im [Zapier-Katalog](https://zapier.com/apps) die Anwendung aus, die Sie mit Dastra verbinden möchten, richten Sie einen Trigger ein und wählen Sie dann die auszuführende Aktion. Sie können Aktionen in einer Drittanwendung aus einem Ereignis in Dastra auslösen oder eine Aktion in Dastra nach einem Ereignis in einer Drittanwendung. Tausende von Anwendungen sind mit Zapier kompatibel.

## Automatisierbare Funktionen von Dastra <a href="#chapter-4" id="chapter-4"></a>

Ein Zap besteht aus einem Trigger und einer oder mehreren Aktionen. Dastra bietet derzeit 2 Trigger und 6 Aktionen an. Die auf Seiten der Drittanwendungen verfügbaren Trigger und Aktionen hängen davon ab, was die Herausgeber der Zapier-kompatiblen Anwendungen bereitstellen. Wir erweitern diese Liste im Laufe der Zeit, damit Sie möglichst viele Funktionen von Dastra automatisieren können.

* **Vorhandene Trigger:**

1. Neue Anfrage einer betroffenen Person erstellt
2. Neue Aufgabe erstellt

* **Vorhandene Aktionen:**

1. Eine Aufgabe erstellen
2. Einen Stakeholder erstellen
3. Eine Anfrage einer betroffenen Person erstellen
4. Einen Stakeholder mit einer bestehenden Verarbeitungstätigkeit verknüpfen
5. Nach einem Stakeholder suchen
6. Einen Stakeholder finden oder erstellen, falls er nicht existiert

Sie können von einem der beiden Dastra-Trigger ausgehen, um Aufgaben in Drittanwendungen auszuführen, oder von einem Trigger einer Drittanwendung, um eine der sechs Aktionen in Dastra auszuführen.
