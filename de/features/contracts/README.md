# Verträge

Das Modul **Verträge** von Dastra ist eine Funktion, die die Verwaltung und Nachverfolgung Ihrer Verträge erleichtert. Es ermöglicht den Nutzern, Verträge sicher zu erfassen, zu bearbeiten, zu unterzeichnen und zu versionieren und dabei die Compliance mit den Datenschutzvorschriften sicherzustellen.

### Zugriff auf das Vertragsmodul

Es ist erforderlich, ein Abonnement mit der Funktion "**Verträge und Richtlinien**" zu besitzen, um auf das Modul zugreifen zu können.<br>

Wenn die Funktion in Ihrem Plan aktiv ist, können Sie auf das Modul zugreifen, indem Sie auf das Vertragssymbol in der Navigation klicken.
