# Ein Dokument erstellen

Um einen Vertrag, eine Richtlinie oder ein anderes Dokument zu erfassen, klicken Sie im Verzeichnis des Moduls **Verträge und Richtlinien** auf **Ein Dokument erstellen**. Ein Assistent bietet vier Möglichkeiten, das Dokument zu erstellen.

<figure><img src="../../.gitbook/assets/contracts-declare-1.png" alt="Das Fenster Ein Dokument erstellen mit den vier Optionen zur Erstellung"><figcaption><p>Die vier Optionen zum Erstellen eines Dokuments</p></figcaption></figure>

| Option | Was sie bewirkt |
| --- | --- |
| **Ein Dokument erstellen** (Option mit KI) | Verfasst das Dokument mit KI auf der Grundlage Ihrer Anweisung. |
| **Bitte importieren Sie Ihr Dokument** | Analysiert eine vorhandene Datei mit KI und füllt die Akte für Sie aus. |
| **Von Grund auf neu** | Erstellt eine leere Akte, die Sie selbst ausfüllen. |
| **Automatisch generieren** | Generiert das Dokument aus einer [dynamischen Vertragsvorlage](templates.md). |

Die ersten beiden Optionen setzen die jeweiligen KI-Funktionen voraus. Sind sie nicht in Ihrem Plan enthalten, sind sie ausgegraut.

## Von Grund auf neu beginnen

1. Wählen Sie **Von Grund auf neu**.
2. Wählen Sie die **Art des Dokuments**: Vertrag, Richtlinie, Hinweis, Vorgehensweise oder Sonstiges.
3. Geben Sie den **Dokumentennamen** ein.
4. Optional: Fügen Sie mit **Dateien hinzufügen** Dateien hinzu. Das ist auch später möglich, sobald das Dokument erstellt ist.
5. Wählen Sie die **Organisationseinheit**.
6. Klicken Sie auf **Ein Dokument erstellen**.

Dastra öffnet anschließend die Akte des Dokuments (siehe [Struktur eines Dokuments](structure.md)).

<figure><img src="../../.gitbook/assets/contracts-declare-2.png" alt="Das Formular zur Erstellung mit den Feldern Art des Dokuments, Dokumentenname, Dateien hinzufügen und Organisationseinheit"><figcaption><p>Das Formular zum Erstellen eines Dokuments</p></figcaption></figure>

## Eine Richtlinie in Dastra verfassen

Ein Dokument ohne Anhang zeigt eine Ablagefläche. Sie können die Datei dort ablegen oder auf **Eine Richtlinie verfassen** klicken, um den Text in einem Editor zu schreiben. Der Text wird zusammen mit den anderen Dateien als Anhang des Dokuments gespeichert.

<figure><img src="../../.gitbook/assets/contracts-declare-3.png" alt="Ein Dokument ohne Anhang mit der Ablagefläche und der Schaltfläche Eine Richtlinie verfassen"><figcaption><p>Die Ablagefläche und die Schaltfläche Eine Richtlinie verfassen</p></figcaption></figure>

## Ein Dokument mit KI generieren

1. Wählen Sie die Option **Ein Dokument erstellen**, die das Dokument mit KI verfasst (die erste Option des Assistenten).
2. Geben Sie eine kurze Beschreibung des Dokuments ein, das Sie generieren möchten. Als zusätzliche Dokumentation können Sie **Anhänge** oder eine **URL der Website** hinzufügen.
3. Klicken Sie auf **Generieren** und prüfen Sie dann die Vorschau.
4. Kontrollieren Sie den **Dokumentennamen** und die **Organisationseinheit** und klicken Sie dann auf **Bestätigen**.

Das Dokument wird mit dem Typ **Richtlinie** erstellt. Den Typ können Sie anschließend über das Badge neben dem Titel ändern.

## Ein vorhandenes Dokument importieren

1. Wählen Sie **Bitte importieren Sie Ihr Dokument**.
2. Wählen Sie die **Organisationseinheit**.
3. Legen Sie eine Datei ab (PDF, DOCX, TXT, Markdown, JPG oder PNG).

Die Analyse beginnt, sobald Sie die Datei ablegen. Der KI-Assistent von Dastra extrahiert die Metadaten aus der Datei (Name, Beschreibung, Tags, Frist, benutzerdefinierte Felder usw.), leitet den Dokumenttyp ab und erstellt die Akte mit der Datei als Anhang. Prüfen Sie die Akte: Die KI-Analyse kann fehlerhaft sein.

## Aus einer Vorlage generieren

Wählen Sie **Automatisch generieren**, um das Dokument aus einer Vorlage zu erstellen. Das Vorgehen ist unter [Vertragsvorlagen](templates.md) beschrieben.
