# Assets

Die Assets umfassen die für die Datensteuerung nützlichen Elemente (wie Datenträger, Räumlichkeiten, materielle oder immaterielle Elemente). &#x20;

Dieses Referenzsystem ermöglicht die Auflistung der Assets, die intern oder extern zur Organisation gehören (Anwendungen, Ressourcen, Gebäude...).&#x20;

Hier geht es darum, die Anwendungen, Software oder Ähnliches einzutragen, die als **Datenträger** dienen.

_Wenn Sie beispielsweise eine CRM-Kundenbeziehungssoftware verwenden, fügen Sie diese in diese Liste ein._

**Das Ziel ist es, Ihnen die Kontrolle über die Datenträger zu ermöglichen und Ihre Assets mit Ihrem Datenkatalog zu verknüpfen.**

NB: Assets sind nicht zwangsläufig mit Auftragsverarbeitern verknüpft. Es kann sich beispielsweise um eine **auf dem Server installierte Software handeln, ohne dass der Herausgeber in die Verarbeitung personenbezogener Daten eingreift**.

### Ein neues Asset hinzufügen:&#x20;

Um ein neues Asset hinzuzufügen, können Sie:&#x20;

* Von bestehenden Vorlagen ausgehen
* KI verwenden
* Ein Asset direkt im Referenzsystem erstellen
* Ein Asset aus einer CSV/Excel- oder JSON-Datei importieren
* Ein Asset aus einem Fragebogen erstellen: Dazu muss ein Fragebogen vom Typ Asset-Erstellung in den Vorlagen vorhanden sein
