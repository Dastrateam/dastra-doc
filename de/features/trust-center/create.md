# Ein Trust Center erstellen

Sie können ein Trust Center über die Startseite der Trust-Center-Funktion erstellen, indem Sie auf "**Ein Trust Center erstellen**" klicken. Diese Option kann gesperrt sein, wenn Sie das Trust-Center-Kontingent Ihres Plans bereits erreicht haben.

<figure><img src="../../.gitbook/assets/trust center3.png" alt=""><figcaption><p>Erstellen Sie ein Privacy Hub, indem Sie auf 'Ein Trust Center erstellen' klicken</p></figcaption></figure>

Sie müssen einen Namen und eine Organisationseinheit angeben, um die Erstellung Ihres Trust Centers abzuschließen

<figure><img src="../../.gitbook/assets/trust center4.png" alt=""><figcaption><p>Ein Trust Center erstellen</p></figcaption></figure>

Sobald das Trust Center erstellt ist, werden Sie zur Bearbeitungsseite Ihres Trust Centers weitergeleitet

<figure><img src="../../.gitbook/assets/trust center5.png" alt=""><figcaption><p>Die Bearbeitungsseite eines Trust Centers</p></figcaption></figure>
