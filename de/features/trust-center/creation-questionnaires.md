# Verarbeitungs-, Vorfalls-, Asset-, Vertrags-, KI-System- oder Stakeholder-Projekte über ein Trust Center erfassen

Die Fragebogenvorlagen sind für die Verwendung mit einem Trust Center konzipiert. Sie funktionieren wie die anderen Vorlagen, aber sobald die Antwort validiert ist, können ihre Daten in ein Dastra-Objekt umgewandelt werden. Es gibt sechs Vorlagentypen:

* **Erfassung von Verarbeitungsvorhaben**: eine Verarbeitungstätigkeit;
* **Erstellung von Datenschutzverletzungen**: ein Datenschutzvorfall;
* **Erstellung von Assets**: ein Asset des Repositorys;
* **Vertragsgestaltung**: ein Vertrag;
* **Entwicklung eines KI-Systems**: ein KI-System;
* **Erstellung eines Stakeholders**: ein Stakeholder.

## Eine Vorlage hinzufügen

1. Öffnen Sie im Modul Fragebögen die Liste **Vorlagen** und klicken Sie auf **Vorlage erstellen**.
2. Wählen Sie im Fenster **Auswahl des Fragebogens** die Option **Basierend auf einer Vorlage**.
3. Filtern Sie in der Bibliothek nach **Typen** oder suchen Sie die gewünschte Vorlage und klicken Sie darauf.

Die Vorlage wird Ihrem Mandanten hinzugefügt und Sie werden zu ihrer Verwaltungsseite weitergeleitet. Damit Besucher sie nutzen können, fügen Sie sie anschließend Ihrem Trust Center hinzu: siehe [Fragebögen](configuration/questionnaires.md). Einzelheiten zur Erstellung einer Vorlage finden Sie unter [Eine Fragebogenvorlage erstellen](../questionnaires/templates/README.md).

## Inhalt der Vorlage

Jede Vorlage enthält eine Liste von Fragen, die die Felder abdecken, die zum Anlegen des entsprechenden Objekts in Dastra erforderlich sind.

## Eine Antwort in ein Objekt umwandeln

Antworten, die über das Trust Center eingehen, erscheinen im Modul Fragebögen in der Organisationseinheit des Trust Centers. Die Schaltfläche zur Umwandlung erscheint erst, wenn die Antwort validiert ist. Sie ist für die Genehmiger der Antwort aktiv.

Auf der Seite der validierten Antwort heißt die Schaltfläche:

* **Anlegen** gefolgt von der Objektart, zum Beispiel **Anlegen (Verarbeitungstätigkeit)**, solange die Antwort nicht mit einem Objekt verknüpft ist;
* **Daten zusammenführen** gefolgt von der Objektart, wenn die Antwort bereits mit einem Objekt verknüpft ist.

Jede Antwort wird mit dem entsprechenden Feld des Objekts verknüpft. Das vollständige Vorgehen finden Sie unter [Antworten in das verknüpfte Objekt übernehmen](../questionnaires/monitor.md#antworten-in-das-verknupfte-objekt-ubernehmen).

## Die Vorlage ändern

Jede Frage ist mit einem Feld des zu erstellenden Objekts verknüpft. Eine Änderung der Vorlage kann daher verhindern, dass Antworten umgewandelt werden. Wir empfehlen, die Vorlage so zu verwenden, wie sie in der Bibliothek bereitgestellt wird.
