# Dokumentvorlagen

Dastra stellt Dokumentvorlagen bereit, zum Beispiel für Ihre Compliance-Dokumentation. Sie finden sie im Modul **Newsfeed**.

1. Klicken Sie im linken Menü unter **Ressourcen** auf **Newsfeed**.
2. Öffnen Sie den Tab **Ressourcen**.

Wählen Sie die benötigte Vorlage aus. Die Vorlagen stehen im Word-Format zum Download bereit.
