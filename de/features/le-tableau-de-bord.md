# Dashboard

## Einführung

Das Dashboard von Dastra ist die erste Seite, auf die Sie beim Betreten Ihres Mandanten zugreifen, und stellt eine Zusammenfassung Ihrer DSGVO-Compliance dar.

Es besteht aus 3 Hauptbereichen:

* Die Funktionsleiste links auf dem Bildschirm,
* Der Community-Tab rechts auf dem Bildschirm,
* Der Bereich in der Mitte mit den Kacheln, die die Neuigkeiten und die Überwachung Ihres Bereichs zusammenfassen, sowie die verschiedenen Funktionen.

![Die Funktionsleiste links auf dem Bildschirm](<../.gitbook/assets/linke funktionsleiste.png>)

![Der Community-Tab rechts auf dem Bildschirm](<../.gitbook/assets/Community Tab.png>)

### Die Kacheln des Dashboards

Im Bereich mit den Kacheln können Sie die Reihenfolge der Kacheln ändern, indem Sie auf die Drag-and-Drop-Schaltfläche klicken, mit der Sie die Anzeigereihenfolge der Kachel verschieben können.

![Ein Beispiel einer Dashboard-Kachel](<../.gitbook/assets/Beispiel einer Dashboard-Kachel.png>)

Es gibt verschiedene **Kachelkategorien** im Dashboard:

* **Aktuelles und Marktbeobachtung**
* **Datenverarbeitungen**
* **Risikomanagement**
* **Compliance**
* **Kanban-Board**
* **Betroffenenanfragen**
* **Cookie-Banner**
* **Aktuelle Vorfälle**
* **KI-Register**
