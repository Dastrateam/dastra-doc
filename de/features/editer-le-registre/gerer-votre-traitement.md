# Eine Verarbeitung anlegen

## Was ist eine Datenverarbeitung?

Eine Verarbeitungstätigkeit ist ein Vorgang oder eine Reihe von Vorgängen, die an personenbezogenen Daten durchgeführt werden, wie z. B. die Gehaltsabrechnung. Alle Verarbeitungstätigkeiten zusammen bilden das Verarbeitungsverzeichnis.

## Eine Verarbeitungstätigkeit erstellen

Um eine Verarbeitungstätigkeit zu erstellen, klicken Sie zunächst im Bereich Verzeichnis auf "**Erstellen Sie eine Datenverarbeitung**".

![Auswahl der neuen Verarbeitung](<../../.gitbook/assets/datenverarbeitung erstellen8.png>)

<figure><img src="../../.gitbook/assets/datenverarbeitung erstellen9.png" alt=""><figcaption></figcaption></figure>

Wählen Sie den Typ der Verarbeitung

Füllen Sie die Beschreibung der Verarbeitungstätigkeit aus, und Sie werden zum Fragebogenbereich weitergeleitet, wo Sie alle erforderlichen Informationen hinzufügen können.

## Verarbeitung als Auftragsverarbeiter erstellen

Um eine Verarbeitung als Auftragsverarbeiter zu erstellen, ist es ganz einfach. Sie müssen beim Erstellen einer Verarbeitung das Kontrollkästchen aktivieren

![](<../../.gitbook/assets/datenverarbeitung erstellen10.png>)

Sie gelangen dann automatisch zur Dokumentationsphase einer Verarbeitung als Auftragsverarbeiter und haben die Möglichkeit, Ihre Verantwortlichen (in der Regel Ihre Kunden) zu deklarieren.

Um eine bestehende Verarbeitungstätigkeit zu bearbeiten, klicken Sie auf die Schaltfläche "Bearbeiten" der Verarbeitung oder gehen Sie direkt zu den Schritten auf der linken Seite des Bildschirms:

![](<../../.gitbook/assets/datenverarbeitung erstellen11.png>)
