# Weiterführende Cookie-Einwilligung

Sobald das Banner eingerichtet ist, muss die Einwilligung auf Ihrer Website angewendet werden, und die erfassten Nachweise müssen nutzbar sein. Die folgenden Seiten beschreiben diese Schritte.

* [Cookies blockieren](../integration/blocking/README.md): Verhindern Sie mithilfe der JavaScript-Ereignisse des Banners, dass Drittanbieterdienste vor der Einwilligung Cookies setzen.
* [Google Tag Manager](../integration/blocking/google-tag-manager.md) und [Google Consent Mode V2](../integration/blocking/google-consent-mode.md): Lösen Sie Google-Tags entsprechend den Entscheidungen der Besucher aus.
* [Einwilligung programmatisch verwalten](../integration/programmatic-consent.md): Lesen und ändern Sie die Einwilligung mit dem JavaScript-SDK.
* [Nutzeridentifikation](../integration/identification.md): Ordnen Sie einen Einwilligungsnachweis einer pseudonymen Kennung aus Ihrem System zu.
* [Die Cookie-Richtlinie generieren](configure.md#die-cookie-richtlinie-generieren): Erstellen Sie die Cookie-Richtlinie aus der Konfiguration des Banners.
* [Die Statistiken anzeigen](consent-proof.md#die-statistiken-anzeigen): Verfolgen Sie Anzeigen, Einwilligungen und Ablehnungen.
