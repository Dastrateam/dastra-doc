# IAB TCF

Das Dastra-Einwilligungs-Widget unterstützt das IAB Transparency and Consent Framework (TCF) derzeit nicht. Keine Option des Banners aktiviert es, und das Widget erzeugt keinen TCF-Consent-String.

Um die Auswahl der Besucher an Google-Dienste weiterzugeben, verwenden Sie Google Consent Mode V2:
