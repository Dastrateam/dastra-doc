# IAB TCF

Das Dastra-Einwilligungs-Widget unterstützt das Transparency and Consent Framework (TCF) des IAB derzeit nicht. Keine Banner-Option aktiviert es, und das Widget erzeugt keinen TCF-Einwilligungsstring.

Um die Entscheidungen der Besucher an Google-Dienste weiterzugeben, verwenden Sie Google Consent Mode V2:
