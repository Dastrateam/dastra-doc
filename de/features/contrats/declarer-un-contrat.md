# Einen Vertrag anlegen

Sie können einen neuen Vertrag erfassen, indem Sie auf die Schaltfläche "**Einen Vertrag erstellen**" auf der Hauptseite des Moduls **Verträge und Richtlinien** klicken.

<figure><img src="../../.gitbook/assets/Verträge und Richtlinien1.png" alt=""><figcaption><p>Erfassen Sie Ihren ersten Vertrag, indem Sie auf 'Einen Vertrag erstellen' klicken</p></figcaption></figure>

Sie können wählen, ob Sie von Grund auf neu beginnen oder einen Vertrag aus einer unserer [dynamischen Vertragsvorlagen](modeles-de-contrats-dynamiques.md) generieren möchten.

<figure><img src="../../.gitbook/assets/Verträge und Richtlinien2.png" alt=""><figcaption><p>Die Optionen zur Vertragserstellung</p></figcaption></figure>

Wenn Sie von Grund auf neu beginnen, müssen Sie lediglich Ihrem Vertrag einen Namen geben, Ihren Anhang hochladen (Sie können den Anhang auch später nach der Vertragserfassung hochladen) und ihn einer Organisationseinheit zuweisen.
