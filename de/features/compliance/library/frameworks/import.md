### Ein Framework aus einer Vorlage erstellen

#### Warum mit einer Vorlage beginnen?

Das Importieren eines Frameworks aus einer Vorlage ermöglicht es, **Zeit zu sparen** und sich auf einen bereits strukturierten Referenzrahmen zu stützen, der den regulatorischen oder branchenspezifischen Best Practices entspricht.

Die von Dastra angebotenen Vorlagen umfassen:

* Die Kapitelstruktur
* Die zugehörigen Anforderungen
* Die Kontrollen
* Die verknüpften Risiken und Bedrohungen

Sie können anschließend an Ihren Kontext **angepasst** werden.

***

#### Schritte zum Import einer Vorlage

{% columns %}
{% column %}
* Klicken Sie auf **Framework erstellen**
* Wählen Sie **Aus einer Vorlage**
* Greifen Sie auf die Dastra-Vorlagenbibliothek zu
* Filtern Sie die Vorlagen nach:
  * Autor (z. B. _Von Dastra erstellte Vorlagen_)
  * Sprache
* Wählen Sie die gewünschte Vorlage aus
* Sehen Sie sich die **Details des Frameworks** an:
  * Anzahl der Anforderungen
  * Kontrollen
  * Risiken
  * Bedrohungen
  * Funktionsbeschreibung
* Bestätigen Sie den Import\
  → Das Framework wird Ihrer Bibliothek hinzugefügt und ist **bearbeitbar**.
{% endcolumn %}

### Ergebnis nach dem Import

{% columns %}
{% column %}
<figure><img src="../../../../.gitbook/assets/Compliance7.png" alt=""><figcaption></figcaption></figure>
{% endcolumn %}

{% column %}
Sie können anschließend die Elemente vor der Erstellung überprüfen.

Alle in Ihrem Framework enthaltenen Objekte werden in Ihrer Bibliothek erstellt.
{% endcolumn %}
{% endcolumns %}

Nach dem Import ist das Framework:

* In der Bibliothek verfügbar
* Kann erweitert oder angepasst werden
* Dient als Grundlage für:
  * **Compliance-Projekte**
  * Die Bewertung der Kontrollen
  * Das Risikomanagement
