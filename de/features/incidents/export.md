# Ihre Datenschutzvorfälle exportieren

Sie können das gesamte Verzeichnis der Vorfälle, eine Auswahl von Vorfällen oder einen einzelnen Vorfall exportieren, zum Beispiel um eine Anfrage der Aufsichtsbehörde zu beantworten oder einen abgeschlossenen Vorfall zu archivieren.

## Das Verzeichnis exportieren

1. Öffnen Sie **Betrieb** > **Vorfälle** > **Verzeichnis der Vorfälle**. Wenden Sie Filter an, wenn Sie nur einen Teil des Verzeichnisses exportieren möchten: Der Export berücksichtigt die aktiven Filter.
2. Klicken Sie auf den Pfeil rechts neben der Schaltfläche **Einen Vorfall hinzufügen** und dann auf **Exportieren**.

   <figure><img src="../../.gitbook/assets/incidents-export-1.png" alt="Menü der Schaltfläche Einen Vorfall hinzufügen mit den Einträgen Importieren, Exportieren, Teilen und Bitte lesen Sie die Dokumentation"><figcaption><p>Das Menü der Schaltfläche Einen Vorfall hinzufügen mit dem Eintrag Exportieren</p></figcaption></figure>
3. Wählen Sie im sich öffnenden Fenster unter **Bitte wählen Sie das gewünschte Exportformat aus.** PDF, Word, HTML, Excel, CSV, JSON oder Markdown.
4. Klicken Sie auf **Datei herunterladen**.

   <figure><img src="../../.gitbook/assets/incidents-export-2.png" alt="Exportfenster mit der Liste der Formate und der Schaltfläche Datei herunterladen"><figcaption><p>Das Exportfenster</p></figcaption></figure>

Der Eintrag **Exportieren** ist ausgegraut, wenn das Verzeichnis leer ist oder Ihre Rolle den Export nicht erlaubt.

## Optionen je Format

* **Zusammenfassung einfügen** für die Formate PDF, Word, HTML und Markdown.
* **Use native column names or reports (recommended for importing data)** und **Export custom fields** für die Formate CSV und Excel. Mit den nativen Spaltennamen können Sie die Datei erneut importieren: siehe [Daten importieren (Excel, CSV)](../general/import.md).

Exporte als PDF, Word und HTML enthalten bis zu 500 Vorfälle, Exporte als CSV, Excel, JSON und Markdown bis zu 10.000. Ist Ihre Auswahl größer, warnt Sie das Fenster, dass nur die ersten Elemente exportiert werden.

## Eine Auswahl oder einen einzelnen Vorfall exportieren

* Aktivieren Sie im Verzeichnis die gewünschten Zeilen und klicken Sie dann in der Aktionsleiste der Auswahl auf **Exportieren**.
* Öffnen Sie im Formular eines Vorfalls den Pfeil der Schaltfläche **Speichern** und klicken Sie dann auf **Exportieren**.

Das Exportfenster ist dasselbe.
