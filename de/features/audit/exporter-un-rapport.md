# Einen Fragebogenbericht exportieren

Sobald die Antworten gesammelt und der Fragebogen validiert wurden, können Sie den Bericht auf verschiedene Weisen exportieren oder teilen.

Aus der Antwortansicht stehen folgende Aktionen zur Verfügung:

* **Einsehen**: Alle Antworten und Bewertungen direkt in Dastra überprüfen
* **Validieren**: Die Antwort genehmigen und auf den Status "Veröffentlicht" setzen
* **Exportieren**: Den Bericht als PDF oder in einem anderen Format herunterladen
* **Archivieren**: Die Antwort archivieren, um Ihren Mandanten übersichtlich zu halten, ohne Daten zu löschen

{% hint style="info" %}
Sie können auch die Fragebogenbewertung und Risikobewertung einsehen sowie automatisch einen Maßnahmenplan generieren, der auf den Antworten der Befragten basiert.
{% endhint %}
