# Einen Fragebogenbericht teilen

Sobald die Antworten vorliegen, können Sie Ihren Fragebogenbericht einsehen, validieren, veröffentlichen, überprüfen, exportieren oder archivieren.

![Beispiel eines Fragebogenberichts](<../../.gitbook/assets/image-141.png>)

{% hint style="info" %}
Sie können auch eine Fragebogen- und Risikobewertung einsehen sowie automatisch einen Maßnahmenplan erstellen lassen, der auf den Antworten der Befragten basiert.
{% endhint %}
