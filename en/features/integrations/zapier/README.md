### About Zapier

Zapier is an online automation tool that connects your applications and services. You can connect two or more applications to automate repetitive tasks without coding or relying on developers.

With Zapier, you set up Zaps (or integrations).

A Zap is an automated workflow that links your applications and services together. Each Zap is made of a trigger and one or more actions. When you turn your Zap on, it runs the actions every time the trigger event occurs.

### The three key concepts <a href="#chapter-1" id="chapter-1"></a>

* **Trigger:**\
  An event that starts a Zap. For example, to send a text message every time you receive an email, the trigger is "new email in inbox".
* **Action:**\
  An event that a Zap performs after it has been triggered. In the same example, the action is "send a text message".
* **Zap:**\
  A trigger and a set of actions, together forming an automated workflow. For example, sending a text message every time you receive an email.

### Templates for a quick setup

We have preconfigured templates of automated workflows that you can set up right away. About ten templates are already available, from our [integrations page](https://www.dastra.eu/en/integrations) or directly in the [integrations section](https://app.dastra.eu/workspace/0/settings/integrations) of the Dastra web application.

We add new templates regularly to meet your automation needs. You can also send us your ideas for automated workflows so that we can offer them as templates.

### A customizable integration editor <a href="#chapter-3" id="chapter-3"></a>

To automate a workflow that has no template yet, or to adapt an existing template slightly, use [the Zapier Zap editor](https://zapier.com/apps/dastra/integrations).

The Zap editor lets you build a Zap from scratch, without writing a single line of code.

Choose the application you want to connect with Dastra in the [Zapier catalog](https://zapier.com/apps), set up a trigger, then select the action to perform. You can trigger actions in a third-party application from an event that happens in Dastra, or trigger an action in Dastra after an event in a third-party application. Thousands of applications are compatible with Zapier.

### Which Dastra features can be automated with Zapier? <a href="#chapter-4" id="chapter-4"></a>

A Zap is made of a trigger and one or more actions. Dastra currently offers 2 triggers and 6 actions. The triggers and actions available on the third-party side depend on what the publishers of Zapier-compatible applications provide. We will add to this list over time so that you can automate as many Dastra features as possible.

* **Existing triggers:**

1. New data subject request created
2. New task created

* **Existing actions:**

1. Create a task
2. Create a stakeholder
3. Create a data subject request
4. Attach a stakeholder to an existing processing activity
5. Search for a stakeholder
6. Find a stakeholder or create it if it does not exist

You can start from one of the two Dastra triggers to perform tasks in third-party applications, or start from a trigger of a third-party application to perform one of the six actions in Dastra.
