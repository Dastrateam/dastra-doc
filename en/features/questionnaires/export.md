# Export a report

Once answers have been collected and the questionnaire validated, you can export the report in several formats or share it by link. Exporting requires the permission to export questionnaires, and the export feature must be included in your plan. Otherwise, the export window shows an unavailability message.

## Export one or several responses

You can start an export from several places:

* **one response**: open it, click the arrow next to the main button, then **Export questionnaire**;
* **several responses**: in a list of responses (**View questionnaires**, **My responses** or a template's dashboard), select the rows and use the **Export** action;
* **all the responses of a template**: in the template's dashboard, click the arrow next to **Plan questionnaire**, then **Export responses**.

The export window asks you to choose a format and options.

### Formats

| Format | Maximum number of items per export |
| --- | --- |
| PDF file (.pdf) | 200 |
| Word document (.docx) | 1,000 |
| Html document (.html) | 1,000 |
| Excel file (.xlsx) | 10,000 |
| Flat file (.csv) | 10,000 |
| Markdown (.md) | 10,000 |
| Json (.json) | 10,000 |

Beyond the limit of the format, Dastra exports the first items only: reduce your selection to retrieve the following ones.

### Options

* **Include annotations**: available for the PDF, Word and HTML formats;
* **Include table of contents**;
* **Include attachments**.

Click **Download file** to start the export. The review comments written by the approvers appear in the report (see [Validate a questionnaire](validate.md)).

## Share the report

A validated response can be shared by link. Open it, click the arrow next to the main button, then **Share questionnaire**. The action is only offered when the response has the **Validated** status.
