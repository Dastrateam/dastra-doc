# Documentation

The documentation requirement stems from the accountability principle recalled in [Article 24 of the GDPR](https://eur-lex.europa.eu/eli/reg/2016/679/oj#d1e3043-1-1).

In practice, this documentation is primarily reflected in the record of processing activities, but also in other elements of data management and GDPR compliance. These may include (but are not limited to) the following elements:

* internal procedures for the creation of a new personal data processing operation (internal control, risk and proportionality assessment, etc.);
* procedure for carrying out DPIAs;
* establishment of written and binding data protection policies to be considered and applied to new data processing operations (e.g. compliance with data quality criteria, prior notice, security principles, consultation, etc.), which should be made available to data subjects;
* mapping procedures to ensure that all data processing operations are properly identified and that an inventory of data processing operations is maintained;
* setting up training programs for the people in charge of data processing management;
* establishment of procedures for managing requests for access, rectification and erasure and the other rights of data subjects;
* setting up an internal complaints management mechanism;
* developing internal procedures for effective data breach management and notification;
* conducting privacy impact assessments in certain circumstances;
* implementation and supervision of verification procedures to ensure that the measures are applied and effective in practice, not just written down (internal or external audits, etc.).

You can also store in this space any document useful for understanding the processing activity, the training notes, and the contracts framing the processing activity if necessary.

## Use the Documentation section

The **Documentation** section of the processing activity offers three tools:

* **Generate information notice**: the AI assistant drafts an information notice for the data subjects from the content of the processing activity. Choose a quick instruction (**Standard**, **Long version**, **Compact**, **1 paragraph**, **Simple** or **Custom**) and the **Notice language**, then click **Generate**. Click **Export** to download the notice as a PDF, Word, HTML or Markdown file; the **Add this file to the attachments of this data processing** option adds the exported file to the attachments. This button is only available when the AI assistant is enabled for your organization. See [AI assistant use cases](../../general/ai-assistant/use-cases.md).
* **Document your data processing here (links)**: a text editor to document the processing activity, for example with links to your procedures or internal documents.
* **Attachments**: drag and drop your files into the upload area, or click **File explorer** to select existing files. Uploaded files are stored in the document management, in a folder named after the processing activity, under **Data processing**.
