# Data subjects

[**Article 30 of the GDPR**](https://gdpr-info.eu/art-30-gdpr/) requires the record to include a description of the categories of data subjects concerned by the processing. Identifying the types of people concerned allows you to analyze the sensitivity of the processing activity and to better assess the risk for the people concerned. For example, a processing activity will not have the same sensitivity if it concerns minors in a hospital as if it concerns a customer file in a shop.

A data subject is any individual whose data is collected, stored or processed within the processing activity. For example, in a recruitment process, every candidate applying for a position is a data subject.

## Add a category of data subjects

1. In the **Data subject** section, click **Add a category of data subjects**.
2. Select the category of data subjects from your directory, or create a new one from the list.
3. Optionally, add **Additional comments**.
4. Optionally, indicate the **Number of data subjects**, that is, the approximate maximum number of people concerned. Choose **Selection** to pick an order of magnitude (from 1 person to fewer than 100,000,000 persons), or **Type a value** to enter a number. For example, for employees, indicate the approximate number of employees in the organization.
5. Click **Add**.

The categories are listed with their maximum volume (**Max volume**). Click a category to edit it, or use the **...** menu to edit or delete it.

## Vulnerable persons

The **Vulnerable natural persons involved** option is set on the category of data subjects itself, in your directory. Select it if the category includes vulnerable individuals, such as people in an unbalanced situation: for example minors, employees or elderly people. The **Data subject** section then shows **Vulnerable persons concerned** for this category.

{% hint style="info" %}
The presence of minors or vulnerable persons and a large number of data subjects increase the **Sensitivity** indicator of the processing activity.
{% endhint %}
