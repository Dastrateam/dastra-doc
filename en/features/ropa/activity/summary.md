# Summary

The **Summary** section is the last section of a processing activity. It gathers, on a single read-only page, all the information entered in the previous sections.

{% hint style="info" %}
Users who can view processing activities but are not allowed to edit them only have access to the **Summary** section.
{% endhint %}

## Choose a view

The buttons at the top of the section switch between four views. Dastra remembers the last view you selected.

* **Detailed view**: one card per section of the processing activity, from **General** to **Documentation**, with an **Impact assessment** card for a data controller activity and a **Controllers** card for a data processor activity. The first card shows the name of the processing activity, its entity and department, its tags, the **Overall progression**, **Quality** and **Sensitivity** indicators, then the internal reference, the description, the workflow state, the creation and last edit dates, the author, the version's description and the [relationships](../relationships.md) with other processing activities. Click **Edit** on a card to go directly to the corresponding section, and use **Collapse all** or **Deploy all** to fold or unfold all the cards.
* **Mapping**: a diagram of the processing activity and of the elements linked to it: purposes, datasets, data subjects, assets, recipients, parties involved and, for a data processor activity, controllers. Click an element to display its details.
* **Section 30**: a table that presents the information required by Article 30 of the GDPR (description, data controller or processor, representatives, data protection officer, purposes, categories of data, data subjects, recipients, data transfers, data retention, security measures and, for a data processor activity, controllers), with the reference of the corresponding paragraph of Article 30.
* **Condensed view**: a simplified presentation of the processing activity in cards, with charts of the data, data subjects and recipients.

## Print the summary

Click **Print** to print the current view.
