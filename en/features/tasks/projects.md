# Create or edit a project or a sprint

In Dastra:

* a project groups tasks, usually around a functional scope;
* a sprint groups tasks to be done over a given period. In French, the same concept is called an iteration.

A task can belong to a project and to a sprint: these are the **Project** and **Sprint** fields of the task panel.

## Create or edit a project

1. In the side menu, click **Tasks**, then **Projects**.
2. Click **Create a project**. Enter the **Name** of the project, with an emoji if you like, and an optional description, then click **Save changes**.

To edit an existing project, click the three dots on its card, then **Edit**.

<figure><img src="../../.gitbook/assets/tasks-projects-1.png" alt="The Projects page with the Create a project button and its drop-down menu open"><figcaption><p>The Projects page</p></figcaption></figure>

Each project card shows the number of closed tasks out of the total number of tasks. Click the name of the project to display its tasks on the **Tasks** page.

### Project actions

The three-dot menu of a card offers:

* **Show tasks**: opens the **Tasks** page filtered on the project;
* **Duplicate project**: creates a copy of the project;
* **Edit**;
* **Move to recycle bin**: removes the project from the list. Select **View recycle bin** in the filters to find it again, then click **Restore** or **Delete**;
* **Export**: downloads the project in the chosen format (CSV, XLSX, JSON or MD).

<figure><img src="../../.gitbook/assets/tasks-projects-2.png" alt="The three-dot menu of a project card with its actions"><figcaption><p>The menu of a project</p></figcaption></figure>

### Import a project or create one from a template

The arrow of the **Create a project** button opens two entries:

* **Create from library...**: creates a project from the library of templates;
* **Import**: opens the **Import a project** window, where you select projects in JSON format. The file must follow the Dastra project template. To see it, first export one of your projects as JSON and open the file.

## Create or edit a sprint

1. In the side menu, click **Tasks**, then **Sprints**.
2. Click **Create a sprint**. Fill in the **Name**, the **Start date** and the **End date**, then click **Save changes**.

To edit a sprint, click the three dots on its card, then **Edit**. The same menu lets you **Show tasks** of the sprint or **Delete** it. A sprint in progress shows the **In progress** mention, a finished sprint the **Done** mention.

<figure><img src="../../.gitbook/assets/tasks-projects-3.png" alt="The Sprints page with two sprints, the Create a sprint button and the menu of a card"><figcaption><p>The Sprints page</p></figcaption></figure>

From the **Tasks** page, the menu of the **Create task** button arrow also offers **Manage sprints**, which opens this page.

### See the tasks of the current sprint

In the **Tasks** menu, the **Current sprint** page lists all the tasks of the sprint in progress.

<figure><img src="../../.gitbook/assets/tasks-projects-4.png" alt="The Current sprint page with the tasks of the sprint in progress"><figcaption><p>The Current sprint page</p></figcaption></figure>
