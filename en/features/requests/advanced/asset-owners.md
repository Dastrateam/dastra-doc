# Request processing interface (asset owners)

When a user is set as the **owner of an asset** linked to a dataset concerned by a request, they get a dedicated interface to process that request. They do not have access to the request list, but they need access rights to the repository.

To open it, go to the **Requests** menu, then **Requests processing**. The **Assets to process** page lists the assets the user is responsible for, and the **Pending requests** page lists the requests waiting for processing, with filters by type and by asset.

Available features:

* View the list of requests to process.
* Open the datasets concerned by the request.
* Provide proofs, and copy or delete the requested data.
* Mark the processing of a dataset as done, or mark it as non applicable, with a comment.

Open a request to see its datasets, grouped by asset. The page offers **View request**, **Mapping** and **Include other datasets**. Click **Process** to see the details of a dataset, then **Mark as done** once the proof is provided or the data is copied or deleted. Click **Mark as non applicable** if the dataset is not concerned: the **N/A** button of an asset applies this status to all its datasets. When all the datasets are processed, Dastra displays **Payload ready**.
