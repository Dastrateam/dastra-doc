# Dastra / eBios RM comparison

Find the correspondence between the eBios RM elements and those of the Dastra risk management module.

| EBios RM             | Dastra                                                |
| -------------------- | ----------------------------------------------------- |
| Objective Aimed (OA) | Dreaded event                                         |
| Sources of Risk (SR) | Threat                                                |
| OA/SR pairing        | Type of risk                                          |
| Context              | Object on which the risk is assessed                  |
| Severity             | Impact (labeled **Severity** in the app)              |
| Likelihood           | Probability (labeled **likelihood** in the app)       |

{% hint style="info" %}
Items missing from this list have the same definition.
{% endhint %}
