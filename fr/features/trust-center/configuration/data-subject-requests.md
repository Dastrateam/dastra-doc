# Exercice des droits

Cette page explique comment afficher dans votre Trust Center un formulaire de collecte des demandes d'exercice des droits.

## Activer la fonctionnalité

Cochez **Exercice des droits** dans la section **Configuration**, comme l'explique [Page d'accueil et configuration générale](home.md). Une page publique **Exercice des droits** est alors ajoutée à votre Trust Center, et la section **Demandes d'exercice des droits** se débloque dans la page d'édition.

<figure><img src="../../../.gitbook/assets/trust-center-data-subject-requests-1.png" alt="Section Demandes d'exercice des droits avec le champ Widget de collecte de demande de droits"><figcaption><p>La section de configuration de l'exercice des droits</p></figcaption></figure>

## Prérequis

* Votre abonnement inclut la fonctionnalité Exercice des droits.
* Vous avez [configuré et publié un widget de collecte](../../requests/widget.md).
* Une clé d'API publique existe dans votre organisation. Sans elle, un avertissement s'affiche dans la page d'édition et le widget ne peut pas fonctionner dans le Trust Center. Pour la créer, lisez [Gestion des clés d'API](../../settings/api-keys.md).

## Choisir le widget de collecte

Dans la section **Demandes d'exercice des droits**, le champ **Widget de collecte de demande de droits** sélectionne le formulaire de collecte à afficher. Un Trust Center n'affiche qu'un seul formulaire.

Tant qu'aucun formulaire n'est sélectionné, la page publique indique que l'administrateur n'a pas configuré de formulaire de collecte.
