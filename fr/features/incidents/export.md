# Exportez vos violations de données

Vous pouvez exporter tout le registre des incidents, une sélection d'incidents ou un incident seul, par exemple pour répondre à une demande de l'autorité de contrôle ou pour archiver un incident clos.

## Exporter le registre

1. Ouvrez **Opérations** > **Incidents** > **Registre des incidents**. Appliquez des filtres si vous voulez n'exporter qu'une partie du registre : l'export reprend les filtres actifs.
2. Cliquez sur la flèche à droite du bouton **Ajouter un incident**, puis sur **Exporter**.

   <figure><img src="../../.gitbook/assets/incidents-export-1.png" alt="Menu du bouton Ajouter un incident avec les entrées Importer, Exporter, Partager et Lire la documentation"><figcaption><p>Le menu du bouton Ajouter un incident, avec l'entrée Exporter</p></figcaption></figure>
3. Dans la fenêtre qui s'ouvre, sous **Choisissez le format d'export que vous souhaitez**, sélectionnez PDF, Word, HTML, Excel, CSV, JSON ou Markdown.
4. Cliquez sur **Télécharger le fichier**.

   <figure><img src="../../.gitbook/assets/incidents-export-2.png" alt="Fenêtre d'export avec la liste des formats et le bouton Télécharger le fichier"><figcaption><p>La fenêtre d'export</p></figcaption></figure>

L'entrée **Exporter** est grisée lorsque le registre est vide ou lorsque votre rôle ne donne pas le droit d'exporter.

## Options selon le format

* **Inclure un sommaire** pour les formats PDF, Word, HTML et Markdown.
* **Utiliser les noms de colonnes ou états natifs (Recommandé pour importer les données)** et **Exporter des colonnes spécifiques** pour les formats CSV et Excel. Avec les noms de colonnes natifs, vous pouvez réimporter le fichier : lisez [Importer vos données (Excel, Csv)](../general/import.md).

Les exports PDF, Word et HTML contiennent jusqu'à 500 incidents, et les exports CSV, Excel, JSON et Markdown jusqu'à 10 000. Si votre sélection dépasse la limite, la fenêtre vous avertit que seuls les premiers éléments seront exportés.

## Exporter une sélection ou un seul incident

* Dans le registre, cochez les lignes voulues, puis cliquez sur **Exporter** dans la barre d'actions de la sélection.
* Dans le formulaire d'un incident, ouvrez la flèche du bouton **Enregistrer**, puis cliquez sur **Exporter**.

La fenêtre d'export est la même.
