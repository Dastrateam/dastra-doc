# Établir votre registre

## Pour établir votre registre dans Dastra, deux possibilités :

* Soit vous disposez déjà d'un registre, et vous pouvez l'importer dans Dastra&#x20;
* Soit vous n'en avez pas, et vous le créez à partir de zéro en vous appuyant sur les modèles de traitement

## Importer votre registre existant

Avec Dastra, vous pouvez importer votre registre des traitements existant au lieu de le saisir à la main, quel que soit son format actuel : fichier Excel, texte ou CSV. Vous pouvez aussi importer des traitements exportés au format JSON depuis un autre espace de travail Dastra.

{% content-ref url="export-import.md" %}
[exporter-importer-le-registre.md](export-import.md)
{% endcontent-ref %}

{% hint style="info" %}
N'oubliez pas de publier vos traitements si vous souhaitez qu'ils soient pris en compte dans le tableau de bord.
{% endhint %}

## Créer un nouveau registre des traitements à partir de zéro

Avec Dastra, un registre est créé automatiquement dès la mise en place de l'espace de travail. Si vous ne souhaitez pas importer de registre existant, vous pouvez commencer tout de suite à remplir ce registre par défaut en créant votre premier traitement. Pour savoir comment faire, suivez ce lien :

{% content-ref url="declare.md" %}
[gerer-votre-traitement.md](declare.md)
{% endcontent-ref %}

Pour gagner du temps sur les traitements courants, vous pouvez aussi partir d'un modèle :

{% content-ref url="templates.md" %}
[utiliser-un-modele-de-traitement.md](templates.md)
{% endcontent-ref %}
