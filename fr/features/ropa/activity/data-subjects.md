# Personnes concernées

{% embed url="https://youtu.be/jdo8zRweCGc" %}

[**L'article 30 du RGPD**](https://www.cnil.fr/fr/reglement-europeen-protection-donnees/chapitre4) demande d'inscrire dans le registre une description des catégories de personnes concernées par le traitement. Identifier les types de personnes concernées vous permet d'analyser la sensibilité du traitement et de mieux évaluer le risque pour ces personnes. Par exemple, un traitement n'aura pas la même sensibilité s'il concerne des enfants mineurs dans un hôpital ou un fichier de clients dans un commerce.

Une personne concernée est toute personne physique dont les données sont collectées, conservées ou traitées dans le cadre du traitement. Par exemple, dans un processus de recrutement, chaque candidat qui postule à un poste est une personne concernée.

## Ajouter une catégorie de personnes concernées

1. Dans la section **Personnes concernées**, cliquez sur **Ajouter une catégorie de personnes concernées**.
2. Sélectionnez la catégorie de personnes concernées dans votre annuaire, ou créez-en une nouvelle depuis la liste.
3. Si besoin, ajoutez un **Commentaire additionnel**.
4. Si besoin, indiquez le **Volume de personnes concernées**, c'est-à-dire le nombre maximum approximatif de personnes concernées. Choisissez **Sélecteur** pour choisir un ordre de grandeur (de 1 personne à moins de 100 000 000 de personnes), ou **Saisir une valeur** pour saisir un nombre. Par exemple, pour les salariés, indiquez le nombre approximatif de salariés de l'organisation.
5. Cliquez sur **Ajouter**.

Les catégories sont listées avec leur volume maximum (**Volume max**). Cliquez sur une catégorie pour la modifier, ou utilisez le menu **...** pour la modifier ou la supprimer.

## Personnes vulnérables

L'option **Personnes vulnérables concernées** se règle sur la catégorie de personnes concernées elle-même, dans votre annuaire. Sélectionnez-la si la catégorie inclut des personnes vulnérables, comme des personnes en situation de déséquilibre : par exemple des mineurs, des salariés ou des personnes âgées. La section **Personnes concernées** affiche alors **Personnes vulnérables concernés** pour cette catégorie.

{% hint style="info" %}
La présence de mineurs ou de personnes vulnérables et un nombre important de personnes concernées augmentent l'indicateur **Sensibilité** du traitement.
{% endhint %}
