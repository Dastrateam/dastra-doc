# Actifs

{% embed url="https://youtu.be/cDB0qfqGaqU" %}

Vous listez ici les actifs, internes ou externes à l'organisation (applications, logiciels, ressources, bâtiments, etc.), qui supportent l'exécution du traitement.

_Par exemple, si vous utilisez un logiciel de relation client de type CRM, ajoutez-le à cette liste._

Cette information, **non obligatoire pour la tenue du registre**, vous permet de **cartographier la chaîne applicative qui relie les données entre elles**.

**L'objectif est de vous aider à maîtriser les supports des données et à lier vos actifs à votre catalogue de données.**

Vous pouvez ainsi **préciser les types de données traitées dans ce traitement**.

NB : les actifs ne sont pas nécessairement liés à des sous-traitants. Il peut s'agir par exemple d'un **logiciel installé sur votre propre serveur, sans intervention de son éditeur dans le traitement des données personnelles**.

## Lier des actifs au traitement

1. Dans la section **Actifs**, cliquez sur **Sélectionner les actifs**.
2. Recherchez les actifs à lier et sélectionnez-les. Si un actif n'existe pas encore, cliquez sur **Créer un actif** pour le créer.

Les actifs liés sont listés dans un tableau. Pour chaque actif, vous pouvez :

* cliquer sur **Ajouter description** pour décrire le rôle de cet actif dans ce traitement ;
* cliquer sur **Synchro. données** pour importer les données de l'actif dans le traitement (voir ci-dessous) ;
* utiliser le menu **...** pour **Modifier** l'actif ou le **Supprimer** du traitement.

## Synchroniser les données de l'actif avec le traitement

Un actif peut déjà être documenté dans votre cartographie, avec son éditeur, ses jeux de données et ses mesures de sécurité. Plutôt que de saisir à nouveau ces informations, vous pouvez les copier dans le traitement.

1. Sur la ligne de l'actif, cliquez sur **Synchro. données**. La fenêtre **Synchronisation des informations de l'actif** liste les éléments qui seraient ajoutés au traitement :
   * **Editeur de l'application à ajouter en sous-traitant**, avec ses pays de transfert ;
   * **Jeux de données associés à l'actif** ;
   * **Catégories de personnes concernées (Liées aux jeux de données)** des jeux de données sélectionnés ;
   * les mesures de sécurité de l'actif.
2. Sélectionnez les éléments à ajouter, ou cochez **Sélectionner tout**.
3. Cliquez sur **Ajouter**.

Les éléments sélectionnés sont ajoutés aux sections correspondantes du traitement : l'éditeur devient un destinataire de la catégorie **Sous-traitant** dans la section **Destinataires**, les jeux de données sont ajoutés à la section **Données**, les catégories de personnes à la section **Personnes concernées** et les mesures de sécurité à la section **Mesures**. Si un pays est renseigné pour l'actif ou son éditeur, un transfert vers ce pays est aussi ajouté au destinataire. Vérifiez-le dans la section **Destinataires**.

La ligne de l'actif affiche l'état de ses données : **Synchronisé**, **Non synchronisé**, ou la date de la dernière synchronisation si l'actif a été modifié depuis.
