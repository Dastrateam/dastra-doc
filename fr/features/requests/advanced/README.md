# Fonctionnalités avancées liées aux exercices de droits

Ces fonctionnalités avancées complètent le traitement des demandes : elles permettent d'automatiser des actions, de déléguer le traitement aux propriétaires d'actifs, de sécuriser les échanges avec les demandeurs, de personnaliser les e-mails envoyés et de maîtriser la durée de conservation des demandes.
