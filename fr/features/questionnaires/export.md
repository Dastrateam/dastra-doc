# Exporter un rapport

Une fois les réponses collectées et le questionnaire validé, vous pouvez exporter le rapport dans plusieurs formats ou le partager par lien. L'export demande le droit d'exporter les questionnaires, et la fonctionnalité d'export doit être incluse dans votre abonnement. Sinon, la fenêtre d'export affiche un message d'indisponibilité.

## Exporter une ou plusieurs réponses

Vous pouvez lancer un export depuis plusieurs endroits :

* **une réponse** : ouvrez-la, cliquez sur la flèche à côté du bouton principal, puis sur **Exporter questionnaire** ;
* **plusieurs réponses** : dans une liste de réponses (**Tous les questionnaires**, **Mes réponses aux questionnaires** ou le tableau de bord d'un modèle), sélectionnez les lignes puis utilisez l'action **Exporter** ;
* **toutes les réponses d'un modèle** : dans le tableau de bord du modèle, cliquez sur la flèche à côté de **Planifier questionnaire**, puis sur **Exporter les réponses**.

La fenêtre d'export vous demande de choisir un format et des options.

### Formats

| Format | Nombre maximal d'éléments par export |
| --- | --- |
| PDF (.pdf) | 200 |
| Word (.docx) | 1 000 |
| HTML (.html) | 1 000 |
| Excel (.xlsx) | 10 000 |
| Fichier plat (.csv) | 10 000 |
| Markdown (.md) | 10 000 |
| JSON (.json) | 10 000 |

Au-delà de la limite du format, Dastra exporte les premiers éléments seulement : réduisez votre sélection pour récupérer les suivants.

### Options

* **Inclure les annotations** : disponible pour les formats PDF, Word et HTML ;
* **Inclure un sommaire** ;
* **Inclure les pièces jointes**.

Cliquez sur **Télécharger le fichier** pour lancer l'export. Les commentaires de revue saisis par les approbateurs figurent dans le rapport (voir [Valider un questionnaire](validate.md)).

## Partager le rapport

Une réponse validée peut être partagée par lien. Ouvrez-la, cliquez sur la flèche à côté du bouton principal, puis sur **Partager le rapport**. L'action n'est proposée que lorsque la réponse est au statut **Validé**.
