# Traduire un questionnaire avec l'IA

Depuis l'éditeur de modèle, l'assistant IA traduit toutes les sections et toutes les questions d'un modèle de questionnaire dans la langue de votre choix. La fonction est désactivée lorsque la fonctionnalité d'IA pour les questionnaires n'est pas activée pour votre organisation.

Pour lancer une traduction :

1. Dans **Modèles de questionnaires**, ouvrez le menu du modèle à traduire, puis cliquez sur **Modifier** pour ouvrir l'éditeur.
2. Dans la colonne de droite, cliquez sur **Traduire le questionnaire**.
3. Choisissez la **Langue cible**.
4. Dans **Enregistrer comme**, choisissez l'une des deux options :
   * **Nouvelle version** : remplace la version actuelle de ce modèle par la traduction ;
   * **Nouveau modèle indépendant** : crée un modèle séparé, sans lien avec l'original.
5. Cliquez sur **Générer**.

<figure><img src="../../.gitbook/assets/questionnaire-translate-button.png" alt="Bouton Traduire le questionnaire dans l&#x27;éditeur de modèle"><figcaption><p>Le bouton Traduire le questionnaire dans l'éditeur de modèle</p></figcaption></figure>

Dastra traduit puis enregistre le résultat directement, selon le mode choisi. La liste des langues est celle des langues de l'application.
