# Questionnaires

Le module Questionnaires de Dastra vous permet de collecter toutes les informations nécessaires au pilotage de votre conformité : AIPD, questionnaires des sous-traitants, questionnaires de conformité, analyses d'impact sur les transferts, et bien d'autres.

Pour accéder au module, ouvrez **Questionnaires** dans le menu de gauche. Le menu propose trois entrées :

* **Modèles de questionnaires** : les modèles que vous créez, importez ou installez depuis la bibliothèque ;
* **Tous les questionnaires** : les réponses à tous les questionnaires planifiés dans l'espace de travail ;
* **Mes réponses aux questionnaires** : les questionnaires qui vous sont destinés, comme répondant ou comme approbateur.

## Répondre à un questionnaire qui vous est adressé

Si vous êtes répondant ou approbateur, ouvrez **Questionnaires** > **Mes réponses aux questionnaires**. La liste n'affiche que les questionnaires qui vous sont adressés, avec leur échéance, leurs répondants, leur statut et leur taux de complétion. Un questionnaire qui a dépassé son échéance porte le badge **Expiré**.

1. Utilisez les onglets au-dessus de la liste pour filtrer par statut : **Tout**, **En attente de validation**, **Validé** ou **Expiré**.
2. Cliquez sur une ligne pour ouvrir le questionnaire et y répondre.
3. Lorsque vous avez répondu à toutes les questions obligatoires, finalisez le questionnaire. Il part alors chez ses approbateurs : consultez [Valider un questionnaire](validate.md).

Le menu d'une ligne propose aussi **Partager**, **Exporter** et **Annuler le questionnaire**, selon vos permissions. Les questionnaires que vous mettez à la corbeille apparaissent lorsque vous activez **Voir la corbeille**, comme décrit dans [Supprimer un questionnaire ou un modèle](delete.md).
