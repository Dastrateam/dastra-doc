# 3. Traiter

L'étape de traitement correspond à la réponse apportée au risque identifié et évalué. Dans la page du risque, elle se trouve dans la section **Traitement du risque**.

Choisissez une option dans le champ **Options de traitement du risque** :

* **Réduction et contrôles** : des mesures doivent être mises en œuvre pour réduire le risque ;
* **Acceptation** : le risque brut est accepté en l'état par l'organisation, sans mesures de réduction ;
* **Évitement** : le risque empêche de faire l'activité concernée ;
* **Transfert du risque** : le risque qui pèse sur l'organisation est transféré à une autre organisation, par exemple via une assurance ;
* **Prendre le risque** : le risque devrait faire l'objet de mesures de réduction, mais l'organisation accepte de ne pas les mettre en œuvre.

<figure><img src="../../../.gitbook/assets/risks-treat-1.png" alt="Section Traitement du risque avec les cinq options de traitement et la justification de la réponse"><figcaption><p>La section Traitement du risque</p></figcaption></figure>

Expliquez votre choix dans **Justification de la réponse**, puis cliquez sur **Valider la réponse** pour passer à l'étape **Surveillance**. Cette décision revient au propriétaire du risque : lui seul peut valider la réponse.

{% hint style="info" %}
Seule l'option **Réduction et contrôles** s'appuie sur les points de contrôle et sur le taux de remédiation, qui font évoluer le risque courant. Pour les autres options, Dastra ne calcule pas de taux de remédiation.
{% endhint %}
