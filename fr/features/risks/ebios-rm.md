# Comparaison Dastra / eBios RM

Retrouvez la correspondance entre les éléments d'eBios RM et ceux du module de gestion des risques de Dastra.

| EBios RM              | Dastra                                                  |
| --------------------- | ------------------------------------------------------- |
| Objectif Visé (OV)    | Évènement redouté                                       |
| Source de Risque (SR) | Menace                                                  |
| Couple OV/SR          | Type de risque                                          |
| Contexte              | Objet sur lequel le risque est évalué                   |
| Gravité               | Impact (libellé **Gravité** dans l'application)         |
| Vraisemblance         | Probabilité (libellé **Vraisemblance** dans l'application) |

{% hint style="info" %}
Les éléments absents de cette liste ont la même définition.
{% endhint %}
