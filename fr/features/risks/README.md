# Gestion des risques

Risques de vie privée, stratégiques, de non-conformité, opérationnels, financiers, liés à la sous-traitance : le module de gestion des risques les rassemble dans un même référentiel. Il s'adresse aux DPO, aux équipes conformité et aux responsables des risques.

Il donne une vision globale de vos risques pour alimenter vos plans de remédiation, étendre votre couverture et réduire votre exposition.

## La gestion des risques dans Dastra en quelques mots

Le module permet d'identifier, d'évaluer, de traiter et de surveiller vos risques dans un même espace, avec une vue d'ensemble de l'exposition de votre organisation.

Avec Dastra, vous pouvez :

* visualiser vos risques par unité organisationnelle, traitement, actif, acteur ou système d'IA ;
* centraliser l'évaluation, le contrôle, le reporting et le suivi des tâches de remédiation ;
* garder les données de risque à jour, fiables et disponibles pour toute l'équipe.

## Associer un risque

Dans Dastra, un risque est associé à un objet parmi les suivants :

* unité organisationnelle ;
* traitement de données à caractère personnel ;
* acteur, par exemple un sous-traitant ;
* actif ;
* système d'IA.

Les types d'objet proposés dépendent des modules activés dans votre espace de travail. Un même type de risque peut être évalué sur autant d'objets que nécessaire.

## Le module en un coup d'œil

Ouvrez **Gestion des risques** dans le menu latéral. Le module est visible avec le droit de lecture sur les risques ; créer et modifier demande le droit d'écriture.

| Entrée du menu | Contenu |
| --- | --- |
| **Vue d'ensemble** | Les indicateurs (risque initial, courant, résiduel, remédiation), la carte de chaleur, les éléments les plus risqués et les derniers points de contrôle. |
| **Risques** | Les risques évalués, avec un onglet par type d'objet. Vous les créez un par un ou en masse. |
| **Types de risque** | Le référentiel des types de risque : évènement redouté, menaces, sources, points de contrôle et pré-évaluation. |
| **Menaces** | Le référentiel des menaces, à réutiliser dans plusieurs types de risque. |
| **Sources** | Le référentiel des sources de risque. |
| **Points de contrôle** | Les mesures qui réduisent le risque, avec leurs réponses successives. |
| **Journal** | L'historique des évènements survenus dans l'organisation, avec leur date et leur impact financier. |
| **Statistiques** | Les scores initial, courant et résiduel par objet (minimum, moyenne, maximum), avec un onglet par type d'objet. |

### Les états d'un risque

Chaque risque passe par cinq étapes, affichées en haut de sa page : **Identification**, **Evaluation**, **Traitement**, **Surveillance**, **Archivage**. Chacune est décrite dans [le processus de gestion des risques](process/README.md).

{% hint style="info" %}
Seul le propriétaire du risque peut changer son état. Il est indiqué dans la section **Identification** du risque.
{% endhint %}

### Créer plusieurs risques en une fois

Dans l'onglet d'un type d'objet de **Risques**, ouvrez le menu du bouton **Créer un risque** et cliquez sur **Création de risques en masse**. Choisissez l'unité organisationnelle, le type de risque, le propriétaire, la date d'identification et les objets concernés : Dastra crée un risque par objet, avec la pré-évaluation du type de risque.
