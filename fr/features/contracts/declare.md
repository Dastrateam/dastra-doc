# Créer un document

Pour déclarer un contrat, une politique ou tout autre document, cliquez sur **Créer un document** dans le registre du module **Contrats et politiques**. Un assistant propose quatre façons de créer le document.

<figure><img src="../../.gitbook/assets/contracts-declare-1.png" alt="La fenêtre Créer un document avec les quatre options de création"><figcaption><p>Les quatre options de création d'un document</p></figcaption></figure>

| Option | Ce qu'elle fait |
| --- | --- |
| **Générer un document** | Rédige le document avec l'IA à partir d'une instruction. |
| **Importer votre document** | Analyse un fichier existant avec l'IA et remplit la fiche pour vous. |
| **A partir de zéro** | Crée une fiche vide, que vous renseignez vous-même. |
| **Générer automatiquement** | Génère le document à partir d'un [modèle de contrat dynamique](templates.md). |

Les deux premières options nécessitent les fonctionnalités d'IA correspondantes : si elles ne sont pas incluses dans votre plan, elles sont grisées.

## Partir de zéro

1. Choisissez **A partir de zéro**.
2. Sélectionnez le **Type de document** : contrat, politique, notice, procédure ou autre.
3. Saisissez le **Nom du document**.
4. Facultatif : ajoutez des fichiers avec **Ajouter les fichiers**. Vous pouvez aussi les ajouter plus tard, une fois le document créé.
5. Choisissez l'**Unité organisationnelle**.
6. Cliquez sur **Créer un document**.

Dastra ouvre alors la fiche du document (voir [Structure d'un document](structure.md)).

<figure><img src="../../.gitbook/assets/contracts-declare-2.png" alt="Le formulaire de création avec les champs Type de document, Nom du document, Ajouter les fichiers et Unité organisationnelle"><figcaption><p>Le formulaire de création d'un document</p></figcaption></figure>

## Écrire une politique dans Dastra

Un document sans pièce jointe affiche une zone de dépôt. Vous pouvez y déposer le fichier, ou cliquer sur **Écrire une politique** pour rédiger le texte dans un éditeur. Le texte est enregistré comme pièce jointe du document, avec les autres fichiers.

<figure><img src="../../.gitbook/assets/contracts-declare-3.png" alt="Un document sans pièce jointe, avec la zone de dépôt et le bouton Écrire une politique"><figcaption><p>La zone de dépôt et le bouton Écrire une politique</p></figcaption></figure>

## Générer un document avec l'IA

1. Choisissez **Générer un document**.
2. Écrivez une description courte du document que vous souhaitez générer. Vous pouvez ajouter des **Pièces jointes** ou une **Url de site Web** comme documentation complémentaire.
3. Cliquez sur **Générer**, puis relisez l'aperçu.
4. Vérifiez le **Nom du document** et l'**Unité organisationnelle**, puis cliquez sur **Valider**.

Le document est créé avec le type **Politique**. Vous pouvez changer le type ensuite, depuis le badge à côté du titre.

## Importer un document existant

1. Choisissez **Importer votre document**.
2. Choisissez l'**Unité organisationnelle**.
3. Déposez un fichier (PDF, DOCX, TXT, Markdown, JPG ou PNG).

L'analyse démarre dès le dépôt. L'assistant IA extrait du fichier les métadonnées (nom, description, tags, échéance, champs personnalisés, etc.), déduit le type de document et crée la fiche avec le fichier en pièce jointe. Relisez la fiche créée : l'analyse de l'IA peut se tromper.

## Générer à partir d'un modèle

Choisissez **Générer automatiquement** pour créer le document à partir d'un modèle. Le fonctionnement est décrit dans [Modèles de contrats dynamiques](templates.md).
