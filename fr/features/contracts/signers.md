# Les signataires

{% hint style="info" %}
Le signataire d'un document est en général une personne physique ou morale **référencée en tant qu'acteur dans Dastra**.
{% endhint %}

Dans l'onglet **Signataires**, indiquez les parties qui doivent signer le document.

Un signataire est un acteur de vos [référentiels](../mapping/repositories/README.md). Pour en ajouter un, cliquez sur **Ajouter acteur**, sélectionnez l'acteur, puis cliquez sur **Ajouter**. Si l'acteur n'existe pas encore et que vous pouvez écrire dans les référentiels, vous pouvez le créer depuis la même fenêtre. L'onglet affiche entre parenthèses le nombre de signataires.

<figure><img src="../../.gitbook/assets/contracts-signers-1.png" alt="L'onglet Signataires avec des signataires dont la signature est enregistrée, en attente ou absente"><figcaption><p>Les signataires d'un document</p></figcaption></figure>

Si l'acteur sélectionné est lié à des actifs, Dastra propose de les lier au document automatiquement : cochez les actifs à ajouter.

Chaque signataire affiche son adresse e-mail, ou l'avertissement **L'acteur n'a pas d'adresse e-mail** lorsqu'elle manque, et l'état de sa signature : **Pas de signature**, **Signature en attente** ou **Signé le** suivi de la date. Vous pouvez gérer la signature de chaque signataire indépendamment (voir [Signer un document](sign.md)).

Comme pour les actifs, la fiche de chaque acteur liste les documents auxquels il est associé.
