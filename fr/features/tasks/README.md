# Planification

Le module Planification regroupe les tâches du plan d'action de votre espace de travail. Vous y créez des tâches, vous les assignez, vous suivez leur avancement et vous les exportez. Il s'adresse aux délégués à la protection des données (DPO) et aux équipes conformité qui doivent pouvoir montrer ce qu'elles ont fait.

## Pourquoi tenir un plan d'action

L'article 24 du RGPD pose le principe de responsabilité (« accountability ») :

> « (…) _le responsable du traitement met en œuvre des mesures techniques et organisationnelles appropriées pour s'assurer et être en mesure de démontrer que le traitement est effectué conformément au présent règlement_ ».

Une fois ses traitements cartographiés et évalués, l'organisation doit mettre en œuvre des mesures techniques et organisationnelles pour les protéger. Le règlement impose de « rendre compte » sans fournir d'indicateurs précis. Un plan d'action clair, partagé et traçable apporte des preuves concrètes : chaque tâche a une personne assignée, une échéance, une étape de suivi et un historique.

## Ouvrir le module

Dans le menu latéral, cliquez sur **Planification**. Le menu se déplie et donne accès à cinq pages :

* **Tâches** : la liste des tâches, avec les vues Colonnes, Tableau, Arborescence et Calendrier ;
* **Statistiques** : les indicateurs et les graphiques d'avancement ;
* **Itération courante** : les tâches de l'itération en cours ;
* **Projets** : les projets qui regroupent des tâches ;
* **Itérations** : les périodes de travail.

<figure><img src="../../.gitbook/assets/tasks-readme-1.png" alt="Le menu latéral avec l'entrée Planification dépliée sur ses cinq pages"><figcaption><p>Les pages du module Planification dans le menu latéral</p></figcaption></figure>

La page **Tâches** s'ouvre par défaut dans la vue **Colonnes**, où les tâches sont réparties par étape.

<figure><img src="../../.gitbook/assets/tasks-readme-2.png" alt="La page Tâches dans la vue Colonnes, avec les tâches réparties en quatre étapes"><figcaption><p>La page Tâches dans la vue Colonnes</p></figcaption></figure>

{% hint style="info" %}
L'entrée Planification n'apparaît que si votre rôle donne accès aux tâches et si le module est activé pour votre organisation.
{% endhint %}
