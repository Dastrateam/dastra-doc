# Créer ou modifier un projet ou une itération

Dans Dastra :

* un projet regroupe des tâches, en général autour d'un périmètre fonctionnel ;
* une itération regroupe des tâches à réaliser sur une période donnée.

Une tâche peut appartenir à un projet et à une itération : ce sont les champs **Projet** et **Itération** du panneau de la tâche.

## Créer ou modifier un projet

1. Dans le menu latéral, cliquez sur **Planification**, puis sur **Projets**.
2. Cliquez sur **Créer un projet**. Saisissez le **Nom** du projet, avec un emoji si vous le souhaitez, et une description facultative, puis cliquez sur **Enregistrer**.

Pour modifier un projet existant, cliquez sur les trois points de sa carte, puis sur **Modifier**.

<figure><img src="../../.gitbook/assets/tasks-projects-1.png" alt="La page Projets avec le bouton Créer un projet et son menu déroulant ouvert"><figcaption><p>La page Projets</p></figcaption></figure>

Chaque carte de projet indique le nombre de tâches fermées sur le nombre total de tâches. Cliquez sur le nom du projet pour afficher ses tâches dans la page **Tâches**.

### Les actions d'un projet

Le menu des trois points d'une carte propose :

* **Afficher les tâches** : ouvre la page **Tâches** filtrée sur le projet ;
* **Dupliquer le projet** : crée une copie du projet ;
* **Modifier** ;
* **Déplacer dans la corbeille** : retire le projet de la liste. Cochez **Voir la corbeille** dans les filtres pour le retrouver, puis cliquez sur **Restaurer** ou sur **Supprimer** ;
* **Exporter** : télécharge le projet dans le format choisi (CSV, XLSX, JSON ou MD).

<figure><img src="../../.gitbook/assets/tasks-projects-2.png" alt="Le menu des trois points d'une carte de projet avec ses actions"><figcaption><p>Le menu d'un projet</p></figcaption></figure>

### Importer ou créer à partir d'un modèle

La flèche du bouton **Créer un projet** ouvre deux entrées :

* **Créer à partir de modèles** : crée un projet à partir de la bibliothèque de modèles ;
* **Importer** : ouvre la fenêtre **Importez un projet**, où vous sélectionnez des projets au format JSON. Le fichier doit respecter le modèle de projet de Dastra. Pour le connaître, exportez d'abord l'un de vos projets en JSON et consultez le fichier obtenu.

## Créer ou modifier une itération

1. Dans le menu latéral, cliquez sur **Planification**, puis sur **Itérations**.
2. Cliquez sur **Créer une itération**. Renseignez le **Nom**, la **Date de début** et la **Date de fin**, puis cliquez sur **Enregistrer**.

Pour modifier une itération, cliquez sur les trois points de sa carte, puis sur **Modifier**. Le même menu propose **Afficher les tâches** de l'itération et **Supprimer**. Une itération en cours porte la mention **En cours**, une itération terminée la mention **Passé**.

<figure><img src="../../.gitbook/assets/tasks-projects-3.png" alt="La page Itérations avec deux itérations, le bouton Créer une itération et le menu d'une carte"><figcaption><p>La page Itérations</p></figcaption></figure>

Depuis la page **Tâches**, le menu de la flèche du bouton **Créer tâche** propose aussi **Gérer les itérations**, qui ouvre cette page.

### Voir les tâches de l'itération en cours

Dans le menu **Planification**, la page **Itération courante** liste toutes les tâches de l'itération en cours.

<figure><img src="../../.gitbook/assets/tasks-projects-4.png" alt="La page Itération courante avec les tâches de l'itération en cours"><figcaption><p>La page Itération courante</p></figcaption></figure>
