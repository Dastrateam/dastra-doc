# Veille et ressources

Le module **Veille et ressources** rassemble ce qui vous aide à tenir votre conformité à jour : les actualités sélectionnées par Dastra, vos propres flux RSS, les fiches pratiques et les modèles, et les webinaires de Dastra. Il s'adresse à tout utilisateur dont le rôle donne accès au contenu.

Pour l'ouvrir, cliquez sur **Veille et ressources** dans le menu de gauche. Le menu comporte cinq entrées : **Vue d'ensemble**, **Actualités**, **Flux d'actualités**, **Ressources** et **Webinaires**.

## Vue d'ensemble

La page **Vue d'ensemble** s'ouvre sur un champ de recherche, **Rechercher des articles, des fiches pratiques, des modèles...**, qui cherche dans les articles, les fiches pratiques et les modèles. Les catégories sont listées sous le champ. Sans recherche, la page affiche les **Derniers articles** et les **Dernières ressources**.

## Actualités

**Actualités** liste les articles publiés par Dastra. Choisissez une catégorie pour affiner la liste. Cliquez sur un article pour le lire. Dans l'article, **Copier l'url de cet article** copie son adresse pour la partager, et **Lire l'article complet** ouvre l'article en entier.

Certains articles sont compilés avec l'aide de l'IA à partir de sources d'actualité publiques. Ils se terminent par une mention qui l'indique. Vérifiez la source avant de vous appuyer sur l'un d'eux pour une décision de conformité.

## Flux RSS

La page **Flux d'actualités** affiche les actualités des flux que vous suivez, en plus des articles de Dastra. Sélectionnez un flux dans la liste de gauche pour lire ses derniers articles. Les flux que vous avez ajoutés sont sous **Vos flux d'actualités**. Les flux partagés avec l'espace de travail par un administrateur sont sous **Flux d'actualités partagés**.

### Ajouter des flux

1. Cliquez sur **Ajouter un flux d'actualités**. Sur une page vide, cliquez sur **Créer votre premier flux RSS**.
2. Sélectionnez un ou plusieurs flux dans la liste prédéfinie. Vous pouvez rechercher dans la liste. Un flux déjà dans votre liste porte le badge **Déjà ajouté**.
3. Cliquez sur **Ajouter les flux sélectionnés**.

Pour suivre un flux qui n'est pas dans la liste, cliquez sur **Ajouter flux personnalisé**, saisissez l'adresse dans **Url du flux d'actualité**, puis cliquez sur **Vérifier le flux d'actualités**. Dastra vérifie l'adresse et lit le flux. Renseignez ensuite un **Nom** et une **Description**, puis cliquez sur **Enregistrer et quitter**.

Les utilisateurs qui ont la permission avancée peuvent partager des flux avec tous les utilisateurs de l'espace de travail. Lorsque vous ajoutez des flux depuis la liste, activez **Partager les flux ajoutés avec tous les utilisateurs de l'espace de travail**. Pour un flux personnalisé, activez **Partager ce flux d'actualités avec les autres utilisateurs de votre espace de travail**.

Si un flux ne peut pas être lu, Dastra indique que son adresse est injoignable ou ne renvoie plus de flux RSS valide. Vérifiez l'adresse auprès de l'éditeur du flux.

### Gérer les flux

Cliquez sur **Gérer vos flux**, ou ouvrez **Réglages espace de travail** > **Flux d'actualités**, pour voir tous les flux de l'espace de travail. Cette page nécessite la permission d'écriture sur la configuration avancée. Pour chaque flux, vous pouvez **Modifier**, **Supprimer**, **Partager avec l'espace de travail** ou **Ne plus partager**, et **Afficher les actualités** pour lire ses articles. Un flux est marqué **Privé** ou **Partagé**.

## Ressources

**Ressources** rassemble les fiches pratiques, les modèles et les documents publiés par Dastra, par catégorie. Parcourez les catégories ou utilisez le champ de recherche de la **Vue d'ensemble**. Ouvrez une ressource pour la lire ou en voir l'aperçu, puis cliquez sur **Télécharger** pour télécharger son fichier. Une ressource affiche son nombre de **Téléchargements**.

Pour utiliser les modèles de documents dans vos propres documents, consultez [Modèles de documents](files/templates.md).

## Webinaires

**Webinaires** liste les sessions en direct animées par les experts Dastra. Choisissez une catégorie à gauche, ou **Tout**. Cliquez sur un webinaire pour ouvrir sa page d'inscription dans un nouvel onglet. Lorsqu'aucune session n'est planifiée, la page indique **Aucun webinaire prévu prochainement.**
