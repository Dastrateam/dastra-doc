# L'aide en ligne

L'aide en ligne de Dastra est accessible à tout moment dans votre espace de travail, depuis le menu de votre profil : cliquez sur votre nom en haut à droite de l'écran, puis sur **Aides**. Un sous-menu s'ouvre avec toutes les possibilités.

<figure><img src="../../.gitbook/assets/getting-started-roles-2.png" alt="Menu du profil avec l'entrée Aides"><figcaption><p>Le menu du profil, avec l'entrée Aides</p></figcaption></figure>

| Entrée | Ce qu'elle ouvre |
| --- | --- |
| **Contacter le support** | Le formulaire de demande de support (voir [Demande de support](request.md)) |
| **Discutez avec nous sur le chat** | Le chat de support |
| **Documentation** | Cette documentation |
| **Base de connaissance** | Les ressources et guides publiés sur le site de Dastra |
| **Dastra Academy** | Les formations de Dastra |
| **Webinaires** | Les webinaires de Dastra |
| **Mon abonnement** | La page de votre abonnement |
| **Support** | L'historique de vos demandes de support |

Le bas du sous-menu donne accès aux pages **A propos**, **Tarification**, **Politique de confidentialité** et **Conditions générales d'utilisation**.

## Les guides

Dastra propose des visites guidées qui présentent une fonctionnalité en quelques étapes. Vous pouvez les relancer à tout moment :

* **Visite de Dastra AI :** dans le panneau Dastra AI, cliquez sur l'icône d'information (**Afficher le guide**) en haut du panneau. Sur le tableau de bord, vous pouvez aussi cliquer sur le badge **Dastra AI** au-dessus de la zone de saisie. La fonctionnalité d'IA doit être disponible dans votre organisation.
* **Visite d'un module :** sur les pages qui disposent d'un guide, cliquez sur le bouton d'information (**Afficher le guide**) pour le relancer.
